## 0. 输出合同（缺一格不合格）

```
Stay Date:
Room Type:              # 未知则先动 BAR / 基础房
Rate Plan:              # BAR 或围栏产品
Current:
Recommended Range:
Preferred（首选）:
Staging:                # 一次 / 分阶段 + 触发器
Do-not-do:
```

给不出点 → **区间 + 首选**。区间宽度通常 BAR 的 5–8% 或 50–100 元（取更贴该店价位的）。涨价首选取中偏低；降价首选取中偏高。

## 1. 先诊断，再动尺

本卡不替代问题树。尺只在下列门打开后使用：

| 方向 | 门（必须） | 打不开时 |
| --- | --- | --- |
| 涨 | Pace Ahead 或 Pickup Fast 至少一条为 Fact，另一条不强烈反向；Remaining 有压力或价明显低 | 不要涨；价已最高 → 只关低价 |
| 降 | 排除口径/曲线后置/供给关/市场冰点/价已最低之后，仍 Pace Behind + Pickup Slow + 价高 | 不降；走 Hold / 修渠道 / 围栏观察 |
| 事件涨 | 事件日期匹配 +（Pace/Pickup/竞对满 之一） | 按普通 Ahead，幅度不建在事件故事上 |

Competitor Rate 参与「锚」，不单独开门。

## 2. 输入 → 强度评分（Hypothesis）

把六维收成 0–2 分。缺项写 0 并降 Confidence。

| 维 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| **Demand / Forecast** | 弱或 Unknown | 中（Constrained 不撞容量） | 强（将撞容量或 Unconstrained≫Cap） |
| **Pace** | Behind ≤−5pp 或 Unknown | On | Ahead ≥+8pp |
| **Pickup** | Slow（Days-to-Sellout > DTA×1.5） | Match | Fast（Days-to-Sellout < DTA） |
| **Remaining 压力** | 厚（按当前速度卖不完） | 中 | 薄（Days-to-Sellout ≤ DTA×0.5 或某型 ≤3 日） |
| **DTA** | >30（窗未到）或 ≤2（另一张卡） | 8–21 | 3–7（尾部窗口，动作更不可逆） |
| **Competitor 位置** | 已 ≥ 全部可订竞对 | 在带内 | 低于最低竞对 ≥8% 或 ≥1 个阶梯 |

**涨分** = Demand + Pace + Pickup + Remaining +（若价低则 Comp=2）。  
**降分** = (2−Demand) + (2−Pace) + (2−Pickup) +（若价高则把 Comp 反向算 2）。  
这是排序尺，不是公式神谕。

## 3. 涨：第一刀启发式（Hypothesis）

与 Increase BAR 卡 **同一套数字**，此处产品化为「何时用哪一档」。

### 3.1 四档（必须能对号）

| 档 | 何时（同时接近） | 第一刀 | 首选怎么取 | 禁止 |
| --- | --- | --- | --- | --- |
| **A · +5%** | 已在竞对带内（价差 <8%）但仍 Ahead+Fast；或只想可逆试探；或事件未证实、只靠 Pace | **+5% 至 +8%** | 对齐最近的竞对点或整十/整五十 | 为「对齐最高」再跳一大步 |
| **B · +8–15%** | Pace Ahead **且** Pickup Fast **且** BAR 低于最低竞对 8–15%；无双确认事件 | **+8% 至 +15%** | 取与「最低～中位竞对」重叠带的中偏低 | 第一刀 >+20% |
| **C · 收到最低竞对** | 低于最低竞对 ≥15% 或 ≥150 元（先到为准）；或价差大但弹性完全未知 | **收到最低竞对附近**（可略上 0–3%） | 对齐最低竞对点（比发明 1017 好） | 一天补完到最高 |
| **D · 不一次跳过最高竞对** | 任何第一刀 | 执行带 **≤ 最高可比竞对** | 第二刀才允许靠近最高 | 第一刀 ≥ 最高竞对；无新信号第三刀 |

**重叠算法（强制）：**

```
方法 A 竞对锚 → 一个带
方法 B 百分比 → 一个带
执行带 = 两者重叠；若无重叠，取更保守的一侧
首选 = 执行带中偏低，并尽量落在某个竞对点上
```

### 3.2 强度如何推档

| 涨分（粗） | 档 | 备注 |
| --- | --- | --- |
| 3–5 | A +5% 或只关破价 | 信号不够，不要 B |
| 6–8 | B 或 C（看价差谁更大） | 默认 Medium |
| 9+ 且事件+竞对满双确认 | B 上沿，允许 +15–20% | 仍受 D 约束；Days-to-Sellout≤3 才讨论 >+20% |
| 价已最高（Comp 维=0）且仍 Fast | **不涨** | 只关低价 / 限配额 / 评 MinLOS（Protect 卡） |

### 3.3 工作锚（Simulation，不是真店）

过程文件 300 间 / BAR 899 / 竞对 999·1029·1099：

```
B：+8–15% = 971–1034
C：最低竞对 999
重叠：999–1034 → 执行带 999–1049
首选：1029（中位竞对，+14.5%）
D：禁止第一刀 1099
```

真实店必须重算。

### 3.4 第二刀

```
触发：24h Pickup ≥ 阈值高（300 间=8 间，p=2.5%）且竞对未降且非一团
动作：在首选上再 +3–8%，或收到最高竞对附近
仍禁止：无新信号 > 最高竞对；精确到个位装最优
```

## 4. 降：对称启发式（Hypothesis）

与 Stimulate 卡兼容，并落实用户要求的 **围栏 −3–5%** 与 **禁止一夜 −15%**。

### 4.1 顺序强制（比幅度更重要）

```
1 供给没开           → 只修供给，不降
2 曲线后置 / Pace On → Hold，不降
3 市场也弱           → 不砸 BAR（do-not-cut 卡）；最多小配额围栏观察
4 价已 ≤ 可订竞对    → 不降；开渠道 / 松限制 / 查产品
5 价高 + Behind + Slow + 已开
     → 先围栏，再考虑动 BAR
```

### 4.2 四档

| 档 | 何时 | 工具与幅度 | 首选 | 禁止 |
| --- | --- | --- | --- | --- |
| **E · 围栏 −3–5%** | 刚过排除、价高于最低竞对 8–15%、DTA 8–21、7D 不是零 | **BAR 不动**；预付/会员/连住 = BAR×(0.95–0.97) 或收到最低竞对附近（取更高者） | 先促销、守 BAR | 促销再低于新地板还叠加 |
| **F · 围栏更深或 BAR −5–10%** | 价高 ≥15% 或 ≥150 元，**且** 7D 也慢，围栏不可用或 48h 围栏已死 | BAR **−5% 至 −10%**，收到最低竞对附近 | 首选取降幅中偏浅（如 −5% 到 −7%） | 一次收到最低竞对之下 |
| **G · 禁止一夜 −15%** | 几乎所有中窗口 | 第一刀不得 −15%+ | — | DTA 4–21 一夜砸 15%+ |
| **H · 短窗例外** | DTA≤3 **且** 近 3D Pickup≈0 **且** 价明显高于全部竞对 | 允许 **−10–15%** 或有截止日期的当晚战术产品 | 有截止日期；不把 BAR 永久砸穿 | 无截止日期的「永久新 BAR」 |

**E 与旧卡 −5–8% 促销的关系：** 第一刀更保守，用 −3–5%。48h 仍死再进入旧卡的 −5–8% 促销或 F 档 BAR。不冲突。

### 4.3 市场也弱时的降幅

**默认 0。** 见 `do-not-cut-price-market-also-weak.md`。若品牌强迫「要有动作」：只开 **小配额** 围栏 E，配额 ≤ 剩余的 20%（Hypothesis），BAR 不动。

## 6. 24 / 48h 触发器（与过程文件同一尺度）

300 间：`阈值 ≈ max(总房×p, 2)`。

### 涨之后

| 24h 净 Pickup | 动作 |
| --- | --- |
| < 3 间（p=1%） | 过激：先守；48h 累计 <5 → 回到第一刀下限 |
| 3–7 | 守首选，不加码 |
| ≥ 8（p=2.5%）且非一团、竞对未降 | 第二刀 +3–8%，仍不跳过原最高竞对除非竞对已再涨 |

### 降 / 围栏之后

| 信号 | 动作 |
| --- | --- |
| 24h ≥ 8 | 刺激够了：关新促销或收到 BAR−3%；已降 BAR 不立刻拉回 |
| 24h 3–7 | 守第一刀 |
| 48h 累计 <5 且供给开 | 第二刀：未动 BAR 则 −5–8%；已动则停价改渠道，**禁止第三刀砸价** |
| 发现渠道昨天是关的 | 撤回降价，开库存 |
| 竞对跟降到我们新价下 | 不自动跟到底；挂 Price War |

取消 24h ≥6 或翻倍：停加码 / 停再降。

## 7. Confidence

- 方向：≥2 个独立家族同向 → 最多 Medium（3 个同向且无翻转缺口 → 方向可偏 High，对外仍常 Medium）。  
- **幅度永远 Hypothesis**，无本店反馈不得 High。  
- 缺竞对：只用百分比档，区间加宽，Confidence 降一档。  
- 缺 Pickup：禁止第二刀；涨最多档 A；降最多档 E 且写 IF。
