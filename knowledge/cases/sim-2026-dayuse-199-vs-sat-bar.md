```
Fact（仿真输入）: 8/29 OTB 148、今日 +6、BAR 799、拟议钟点 199 到 20:00、Remaining 32、竞对一家满
High-probability: 晚到仍会来。20:00 钟点会挡 15:00–20:00 入住

```

**主诊断：** 周六过夜 **Ahead + 剩余偏紧 + 拟议钟点挡夜**。  
**不要全开 199 钟点。不要改 BAR。不要一夜 −15%。**  
**问题树：** 钟点房占晚房。  
**Naive「下午很火所以晚上让路」：不对。** 火的是小时需求；晚上还在卖 799 过夜。

与 P05：过夜 dump 本不应在 Ahead 夜开；钟点更不是过夜 dump 的合法替身。  
与 P40：压缩夜被小时产品占满，与 Sat-only 过夜占满同一瓶颈。  
与 T19：挡夜时 199 对 799 的机会成本不是 0。
