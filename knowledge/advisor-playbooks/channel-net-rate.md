## 0. 一句话

从 Gross ADR 升到 **Net Contribution**，决定 **保哪个渠道、砍哪个批发、高峰收谁的配额**。  
缺费率：只比结构，**不算假精确净额**。禁止编造佣金%。

完成定义（BACKLOG）：净价公式按任务书 §23 / 净贡献卡落地；缺费率只比结构。

## 2. 公式（声明制，与净贡献卡同一套）

```
Net_c = Gross_c − Commission_c − Discount_c − Marketing_c − Distribution_c
NetADR_c = Net_c / Sold_c
```

缺任何一项：算能算的，并写「低估了直销或低估了 OTA」。  
禁止用「行业平均佣金」填空。  
STR ADR ≠ 本式（批发常已净，OTA 常毛）。

中国四平台 2026 统一官方佣金表：**未找到**（NV-CH-01）。Booking Partner Help（已核）：佣金看合同，随国家/类型变，帮页无全球单一 %。博客 15% / 12–18% / 4.5–8% = C/D，**不采用**。

## 4. 动作（落到日期 × 渠道）

| 现象 | 动作 |
| --- | --- |
| 合同费率齐，某 OTA 净 < 直销净，且占高峰 | 该 Stay Date：**收**该渠道低价配额（Hypothesis：剩余 30–50% 或关破价）；BAR 层保留可订 |
| 费率 Unknown | 只写结构：高峰关批发/破价；弱日高佣渠道只要增量且看起来净>0 可留；**不报「省 87 元/间」** |
| 批发/净价在压缩日仍开 | **关或限额**；与 BAR 比用净，不比毛 |
| 直销公开价 > OTA（倒挂） | 先修平价或直销优势，再谈 mix（监管后「全网最低」执行以用户后台为准，不编整改细则） |
| 弱日、Pace Behind、该渠道是仅有增量 | 留；净能算则净>0 才留 |
| 用户问「是不是 15%」 | 要合同。中国 OTA：NV。Booking：看协议 |

```text
Stay Dates:
Channel:            直销 / 携程 / 美团 / 飞猪 / 同程 / Booking / 批发 / 其他
Gross ADR / 已知成本 / NetADR（或「费率 Unknown，结构：…」）:
Decision:           保 BAR 层 / 收低价配额 / 关批发 / 先修平价 / 弱日留增量
Quota:              压缩日低价渠道 → 剩余 30–50%（Hypothesis）或关 < 新地板
Do-not-do:
  - 按 Gross ADR 排名保渠道
  - 编佣金%
  - 道德反 OTA（关光主渠道制造假低 OCC）
  - 「适当调整渠道结构」
```

## 5. Trigger

| 事件 | 动作 |
| --- | --- |
| 收配额后 24h 总 Pickup 塌、直销没接住 | 弱日可把 BAR 层配额开回；**不**重开破价 |
| 发现仍有公开 < 地板 | 先关产品，再谈 mix |
| 用户补合同费率 | 重算净排序，只改该日动作 |
| 竞对自杀价只在某一 OTA | 不跟（P16）；本店该渠道也不降净去打 |

## 6. 如果只能再补 3 个

1. 用户合同佣金 / 神券谁出（翻转净排序）  
2. 分渠道间夜 + Gross（至少直销 vs 最大 OTA vs 批发）  
3. 高峰日这些渠道是否仍开破价
