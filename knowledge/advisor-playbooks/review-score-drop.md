## 0. 一句话

评分掉了先修图、设施和近窗差评，不是先砍 BAR 换量。  
口碑是转化信号，不是需求曲线，更不是报价器。  
没有评分截图就不发明 4.3，也不发明平台红线。

完成定义：一张「评分→要不要动 BAR」过程。P35 管排名检查单；本剧接管 **评分当砍价理由** 这一问，不复制整棵排名树。

| 形 | 看起来 | 实际 | 默认动作 |
| --- | --- | --- | --- |
| **A 无截图** | 口述 4.8→4.3 / 「卫生分低于 4.7」 | 数字未核；红线 = NV | 检查单。不发明 4.3/红线。**Hold BAR** |
| **B 分掉 + Ahead** | 「先降保住量」 | 需求还在 | **Hold / P09 只关不涨。** 修内容。永不砍 |

| **D 分掉 + 洗掉口碑恐慌后真弱** | 「口碑+没需求必须 dump」 | 弱需求另有围栏 | **P02/P05 围栏。** 禁一夜 −15%。仍修 ops |

顾问必须能直接说的三句：

```
1. 评分掉了先修图、设施和近窗差评，不是先砍 BAR 换量。
2. 口碑是转化信号，不是需求曲线，更不是报价器。
3. 没有评分截图就不发明 4.3，也不发明平台红线。
```

独立默认（本库 Hypothesis）：砍价 **不提高** 评分。它最多换一批对价更敏感、对品质更不敏感的客人，把更便宜的预期写进下一批评论。Anderson 2012 的方向是口碑更好 → **定价权更强**，不是「口碑差了就该更便宜」。

## 3. 分叉闸（动 BAR 前必过）

评分是 **质量 / 转化信号**。它解释「客人看见你之后还肯不肯付这个价」，不解释「市场今晚有没有人出门」，更不输出 BAR 数字。

```
0  证据。无截图 → 检查单，不发明 4.3 / 4.7。Hold。
1  假口碑危机。库存关 / 限制挡 / 主 BAR 关着只剩深折 → 先修那些（P35 X1–X3）。停价。
2  评分稳定、转化掉 → 离开本剧主因。P35/P36/P33/P02。
3  评分掉 + Ahead / Peak → Hold；P09 只关不涨。修内容。不砍。
4  评分掉 + 库存/价/排名也坏 → 那些先修。评分不当砍价令。
5  评分掉 + Pace On 或略 Behind、市场不冰、价可比 → 默认 Hold。动作在内容/运营。
6  洗掉口碑恐慌之后仍真弱 + 价真出局 + 市场不冰 → P02/P05 围栏。禁一夜 −15%。评分仍不是砍的「因为」。
7  「买回口碑」报名 → 整段 P18。Unknown 出资或 Peak → 不报。
```

**禁止跳到砍 BAR 而不做 0–5。** 砍价修不了分：下一批评论仍读到坏空调、过期主图。更深的公开价会训练「这家就该这个价」的客群（T20），且可能穿 T19。

与 P35：**排名诊断仍先**，若原话是「排名掉了」。本剧不复制库存/比价/玄学整树；只在闸 1/4 把那些故障标成「先修、仍不因评分砍」。

与 P16：口碑恐慌不是价格战。价差 <8% 且 Pace 不差 → 不跟。

与 Anderson 2012：**只用方向**（更好口碑 → 更强定价权）。禁止倒置成「降 0.1 分 → 转化掉 X%」或「分掉了所以 −15%」。样本数字不进启发式。

## 5. 十步过程（顾问内部，可对用户压缩）

```text
1. 钉 Stay Date / DTA / Pace/Pickup。没有日期仍条件化，不说无法判断。
2. 要评分证据：平台原名、截图今 vs 近窗、近窗差评主题。无截图 → 检查单，不编 4.3 / 4.7。
3. 排除假口碑危机：库存、限制、ARI、主 BAR 是否开（P35 X1–X3）。关着 → 开，停价。
4. 分叉：评分稳定？Ahead？库存/价/排名也坏？Pace On 且价可比？洗完才真弱？
5. 运营杠杆（用户做）：换主图、勾设施、修近窗投诉（空调/卫生/承诺）、回复差评。顾问不代操作。
6. 价：默认 Hold。输出区间+首选。拒绝为评分 dump。
7. 有人要报今夜特价「买回」→ 整段 P18。Unknown 或 Peak → 不报。
8. 真弱且价出局且已排除口碑恐慌 → 才围栏 −3–5%。DTA≤3 → P05。禁一夜 −15%。
9. 贡献 / 品牌底：穿 T19 不卖；有声明底不砸穿（T20）。无地板不发明 699。
10. 输出：Hold / 修内容 / 不报 / 移交 P02·P05·P18 + 价区间+首选 + 再要 3 个数 + Trigger。
    不输出权重公式、不输出 0.1 分弹性。无截图声明 Hypothesis / Low confidence。
```

### 5.2 价（Hypothesis；点或区间）

幅度仍走 `pricing/how-much-to-move.md`。本剧只回答 **别为评分先砍**。

| 判定 | BAR | 内容 / 报名 |
| --- | --- | --- |
| 无截图 / 口述-only | **Hold**。可给心理带（例现行 799 → 779–799 首选 799），**不是**已经降了 | 检查单。不发明 4.3 |
| 分掉 + Ahead / Peak | **Hold** 或 P09 只关不涨 | 修体验，避免 Ahead 卖成差评燃料。不报名 |
| 分掉 + Pace On/略 Behind、价可比、市场不冰 | **Hold**。区间同上 | 主图/设施/近窗差评/回复 |
| 分掉 + 库存/价/排名故障并存 | 先修那些；BAR 默认 Hold | 评分不当这一刀的理由 |
| 洗完仍真弱 + 价出局 + 市场不冰 | 档 E 围栏 −3–5%；48h 死再评档 F | 窗口/内容保持修；不要反过来 dump 公开 BAR |
| DTA≤3 过 P05 排除 | 档 H 短窗战术；有截止日期 | **禁止一夜 −15% 当新 BAR** |
| 「买回口碑」今夜特价 | BAR 不动 | P18：Unknown / Peak → **不报** |
| 价已最高 | 只关不涨 | 内容仍修 |
| 市场也弱 | 不砸公开 BAR（do-not-cut） | 内容仍修；最多自有小配额围栏 |

价格带标 **Hypothesis**。案例数字标 **Simulation**。禁止写成某店 Fact。  
4.3 / 4.8 不是库内门槛。出现在案例里必须标 Simulation。

## 6. Trigger

| 事件 | 动作 |
| --- | --- |
| 用户补截图，分数其实稳定 | 离开本剧主因。转 P35/P36/P02 |

| 投诉其实是「排名掉了」 | **P35** 先。本剧退出主座 |

## 7. 如果只能再补 3 个
