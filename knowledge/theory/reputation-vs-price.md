## 0. 一句话

**评分掉了先修图、设施和近窗差评，不是先砍 BAR 换量。**  
口碑是 **质量 / 转化信号**：客人看得到你之后，还肯不肯点、肯不肯付这个价。它 **不是** 需求曲线（市场今晚有没有人出门），**更不是** 报价器（BAR 该标多少）。

```
Naive（禁止）     4.8→4.3 → 降价换量；差评多了报今夜特价；没截图也发明红线
本卡              评分 = 转化/质量。修内容与近窗运营。Hold BAR。
                  报名买曝光仍走 P18。Pace Ahead 更不砍。
不是              P35 排名诊断（库存/比价/内容/曝光位）
不是              P16 竞对 dump
不是              P38 取消窗
不是              STR Occupancy / ADR 公式里的一项
```

完成标准：用户说「评分从 4.8 掉到 4.3，要不要降价换量？」「差评多了要不要报今夜特价？」→ 先要评分截图与近窗差评主题；缺截图不发明 4.3、不发明平台红线；默认 Hold BAR，动作在内容/运营；真弱需求另走 P02/P05，禁止一夜 −15%。

顾问必须能直接说的三句：

```
1. 评分掉了先修图、设施和近窗差评，不是先砍 BAR 换量。
2. 口碑是转化信号，不是需求曲线，更不是报价器。
3. 没有评分截图就不发明 4.3，也不发明平台红线。
```

独立默认（本库 Hypothesis）：砍价 **不提高** 评分。它最多换一批对价更敏感、对品质更不敏感的客人，把更便宜的预期写进下一批评论。Anderson 2012 的方向是口碑更好 → **定价权更强**（同样份额可以要更高价），不是「口碑差了就该更便宜」。

## 1. 评分是什么（以及不是什么）

| 对象 | 是 | 不是 |
| --- | --- | --- |
| **点评 / Guest Review Score** | 已住客对体验的质量投票；影响后续客人的 **转化** 与部分平台的 **筛选/可见性** | 需求曲线；BAR；STR Occupancy |
| **内容完整度 / 主图 / 设施勾选** | 可观察的店内杠杆；信息不符会制造差评 | 平台排序权重表 |
| **近窗差评主题** | 运营事故清单（卫生、设施坏、承诺不符） | 「市场没人出门」的证据 |
| **STR Occupancy / ADR / RevPAR** | Sold / Available；Room Revenue / Sold | **公式里没有评分。** 禁止发明 STR Review Index |

STR/CoStar Glossary（**打开** 2026-08-23）：Occupancy = Rooms Sold / Rooms Available；ADR = Room Revenue / Rooms Sold。词条级 **无** Review / Reputation / Guest Score。口碑可以 **解释** 为什么转化差，但不能改写 OCC 公式，也不能当市场 Pace。

Booking Partner（**A Vendor，仅 Booking**，2026-08-23 打开）：

- Guest Review Score 来自在该平台订过的客人；2025-01 起 **近窗评论权重更高**。高分有助于可见性，且客人会用评分 **筛选**。
- 改善路径写的是：信息正确、照片新、回近窗差评并 **修问题**、现场服务——**不是** 降 BAR。
- 排序 FAQ 点名 conversion、ADR、取消、property page score、Guest Review Score。**无权重%。** 抄到美团/携程 = Hypothesis 清单，不当 Fact。
- Property page score = 内容完整度检查单。Vendor 称 100% 相对内容不全可至多 +18% 预订。**不进中国启发式，不当本店保证。**

HSMAI（**A 协会实践**）：OTA 位次受内容完整度影响；有的第三方有 completeness score；信息错/不清 → 差评 → 更差位次。价/内容不一致伤害可见性。动作是 **审计内容**，不是砍公开 BAR。

**评分 ≠ 排名 ≠ shopper：**

| 用户原话 | 走哪 |
| --- | --- |
| 美团/携程排名掉了、流量没了 | **P35**（先查库存/比价/内容；不先砍 BAR） |
| 截图里隔壁便宜 80 | **P36**（先问同一口价） |
| 评分掉了 / 差评多了要不要降价或报今夜特价 | **本卡**（修内容/运营；Hold BAR；报名仍 P18） |
| 竞对连续砸价 | **P16**（口碑恐慌不是跟到底的理由） |

评分 **可以** 造成排名掉（P35 内容枝）。本卡回答的是 **评分 → 要不要动 BAR**，不重写 P35 的排名诊断枝。

## 2. 误诊：把质量信号当成需求曲线

| # | 看见 | 读成 | 实际 | 动作 |
| --- | --- | --- | --- | --- |
| **Q1** | 评分掉 / 近窗差评潮 | 「没人要，砍 BAR / 报今夜特价」 | 转化在掉，因为产品或预期坏了 | **修**：主图、设施、近窗投诉运营、回复差评。Hold BAR |
| **Q2** | 转化掉、**评分稳定** | 「口碑不行所以要降」 | 不是口碑问题 | 查库存/限制（P33/P37）、价是否出局、排名（P35）、shopper 口径（P36） |
| **Q3** | 评分掉、**Pace 仍 Ahead** / Pickup 快 | 「先降保住量」 | 需求还在；质量信号尚未杀死这条 Stay Date | **不砍**。可 Hold / 按 P09 只关不涨或小抬。先修体验，避免把 Ahead 卖成差评燃料 |
| **Q4** | 评分掉、Pace Behind、市场也空 | 「口碑+没需求，必须 dump」 | 市场冰时弹性差（do-not-cut） | **不砸公开 BAR**。内容仍修。真弱走 P02 围栏，禁一夜 −15% |
| **Q5** | 销售：「不报今夜特价排名回不来」 | 用促销买回口碑 | 报名是分销动作，不是修分 | 整段 **P18**：谁出资、净价、Peak。口碑 FOMO 不当门 |
| **Q6** | 无截图，口述 4.8→4.3 / 「卫生分低于 4.7」 | 当 Fact 开刀 | 数字未核；4.7 红线 = 自媒体 D | **不发明 4.3，不发明红线。** 只要检查单。Confidence Low |

砍价 **修不了分**：下一批评论仍读到旧房、坏空调、过期主图。更深的公开价会训练「这家就该这个价」的客群，伤害 T20 价格带，且可能穿 T19 贡献。

## 3. 弹性：质量驱动的转化塌不是 η 高

`pricing/price-elasticity-advise.md` 回答的是：**上一刀价动了之后，量有没有把价差赚回来？** 本卡加一条边界：

```
转化掉 + 评分掉 / 近窗差评主题清楚
  → 这是质量/预期故障，不是「价太高所以 η 很大」
  → 禁止据此开 BAR −5–10% 或一夜 −15%
  → 先修供给与内容；价默认 Hold

转化掉 + 评分稳定 + 价明显高于全部可订 + Pace 真落后 + 市场不冰
  → 才进入 how-much-to-move 围栏 −3–5%；仍禁一夜 −15%
```

Anderson, C.K. (2012) Cornell CHR Vol.12 No.15 *The Impact of Social Media on Lodging Performance*（Mandarin 译本 bitstream **打开**；eCommons 英文 handle **仍 429**；Virginia Tech Feiertag 文摘 **打开**）：Travelocity 样本上，评分在 5 分制 **升 1 分**，酒店可以 **提价** 仍维持份额；ReviewPro GRI 与 STR 匹配回归：口碑升 → ADR/OCC/RevPAR 方向为正。

**本库用法（硬边界）：**

- 用 **方向**：更好的口碑给 **定价权**，不是给砍价许可证。
- **禁止** 把 11.2% / 0.89% / 0.54% / 1.42% 写成今晚 BAR 幅度或中国 OTA SOP。
- **禁止** 倒置成「降 0.1 分 → 转化掉 X%」当 Fact（用户原话 4.8→4.3 不是库内门槛；样本也不是 0.1 分弹性表）。
- 2012、Travelocity / ReviewPro GRI / STR 北美匹配样本。不是美团/携程卫生分。

点 η 仍 NV（M7）。质量故障时连「相对弹性够」都还没轮到测。

## 4. 顾问过程（不是 P39 剧本）

本小时只给理论 + 决策卡。完整 Diagnose→Advise 剧本留给 10:17。顾问今晚仍可调用：

```
1. 证据：平台原名、评分截图（今 vs 近窗）、近窗差评主题、是否只是口述。
   无截图 → 检查单，不发明 4.3 / 4.7 红线。
2. 先排除假口碑危机：库存关、限制挡、ARI 不同步、主 BAR 关着只剩深折（P35 X1–X3）。
3. 分叉：
   评分稳定、转化掉 → 不是本卡主因。P35/P36/P33/P02。
   评分掉、Pace Ahead → Hold / 按 P09；修内容。不砍。
   评分掉、Pace Behind、市场不冰、价已可比 → 仍默认 Hold BAR；修内容。
   评分掉、价真出局且真弱（洗掉口碑恐慌之后） → P02/P05 围栏，禁一夜 −15%。
4. 运营杠杆（用户做，顾问不代操作后台）：换主图、勾设施、修近窗投诉（空调/卫生/承诺）、回复差评。
5. 有人要报今夜特价「买回」曝光/排名 → **P18**。出资 Unknown 或 Peak → 不报。
6. 贡献 / 品牌底：穿 T19 不卖；有声明底不砸穿（T20）。无地板不发明 699。
```

幅度数字不改：围栏 −3–5%；BAR −5–10%；禁止一夜 −15%；价已最高只关不涨。

## 5. 短节：不要把评分写成 STR 指标

| | 评分 / 口碑 | OCC / ADR / RevPAR |

| 顾问用法 | 转化/质量诊断；内容检查单 | 量价结果 |
| 缺数时 | 不编 4.3 / 4.7 | 不编 OCC% |
