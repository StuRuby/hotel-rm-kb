> **无默认闪促折扣 %、无「秒杀必须 X 小时」、无「卖爆了必须改 BAR」、无佣金%**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 闪促 / 秒杀 / 限时挂牌（用户给；不编）
- gap = 公开 BAR − 闪促挂牌（只观察，不推导必须折扣）
- 闪促 Booking/Stay 截止日是否已知、是否已过
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成闪促价 / 窗过了继续挂」

## 不用来做什么

- 不推导「闪促该便宜多少」
- 不把闪促挂牌写成公开 BAR
- 不因「卖爆了」自动砍/涨公开尺
- 不把 PriceLabs / OPERA 例示写成中国 Fact
- 不发明秒杀时长 / 佣金%

## 调用

早会/调价前看：公开 BAR；闪促是否被当成尺；有没有人要求 BAR→闪促价或过期还挂。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁闪促借口一夜 −15%；围栏须有截止日）。

本店闪促 SOP / 华住字段 / 默认折扣 = **NV**。
