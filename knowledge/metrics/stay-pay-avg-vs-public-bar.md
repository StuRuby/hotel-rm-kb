# Metric｜Stay-Pay Average vs Public BAR（轻）

> 路径：`metrics/stay-pay-avg-vs-public-bar.md`  
> 配：P76  
> 状态：drafted 2026-08-29 18:17  
> **无默认免费晚 %、无「连住必须打 X 折」、无「过账摊平 = 市场价」、无佣金%**

## 定义（Hypothesis 计数尺）

- 本店公开灵活单晚 BAR（用户给）
- 连住促销挂牌 / 客人算出的单晚均价（用户给；不编）
- gap = 公开 BAR − 促销摊平均价（只观察，不推导必须折扣）
- 是否 Stay X Pay Y / 免费晚过账 / Buy X Get Y（能拆就拆；拆不清标 NV）
- 促销是否带 MinLOS / 资格 / 卖窗
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成连住均价 / 过账摊平所以跟」

## 不用来做什么

- 不推导「连住该便宜多少 / 免费晚该占几成」
- 不把促销摊平均价写成公开 BAR
- 不因「连住更划算 / 过账摊平了」自动砍公开尺
- 不把 OPERA Vendor $ 例 / WebRezPro 30%/20% 写成中国 Fact
- 不发明免费晚 % / 佣金% / Stay 3 Pay 2 折扣

## 调用

早会/调价前看：公开 BAR；连住促销是否被当成尺；有没有人要求 BAR→摊平价。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁连住均价借口一夜 −15%；围栏须有截止日）。

本店连住促销 SOP / 华住字段 = **NV**。
