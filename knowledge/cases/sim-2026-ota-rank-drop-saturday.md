## 1. Intake

口径：Pickup 为间夜。OO=0 Hypothesis。独立店自有围栏。  
排名 = **口述-only** → 只给检查单，不给权重公式。  
美团标准房 0 = **库存关了**（X1），不是算法已判决。  
679 vs 799 = −15.0%，命中「一夜 −15%」禁令。  
佣金 / 变动成本 / 官方权重 = **Unknown**，不编。

四价（今晚）：

| 层 | 现行 |
| --- | --- |
| 公开 BAR | 799 |
| 美团标准房 | **不可订**（0） |
| 今夜特价意向 | 679（相对 BAR −15%；出资 Unknown） |
| 竞对带 | 749–829 |

价差：799 vs 最低可订竞对 749 = **+6.7%**，未到「明显高于全部」的 8–15% 启发式。价 **未最高**（829 更高）。Pace 相对 STLY **约 −3pp**，不是 Ahead，也不是深落后。

**预选 3 个补数：** 美团标准房能否立刻开回；今夜特价谁出资；同日竞对比价截图（含是否含早）。
