## 定义（Hypothesis 计数尺）

- 公开灵活 **EP / 裸房** 价
- 同房型 **CP / 含早 / 套餐** 挂牌价（若有）
- gap = 套餐挂牌 − EP（只作观察，**不是必须加价指令**）
- 本店 Pace（Ahead / On / Behind）+ Remaining
- 用户口头「BAR」指向：EP / 套餐 / 混用 / Unknown

## 不用来做什么

- 不推导「含早该加多少 % / ¥」
- 不把 gap 写成必须对齐竞对含早
- 不因 gap 小就砍 EP
- 不因 gap 大就把套餐标成新 BAR
- 不把 OTA 全额佣金争论写成砍 BAR（那是 P20）

## 调用

早会/调价前看：用户说的 BAR 是不是 EP；套餐是否被误标为 BAR；EP 是否仍 Hold。  
Ahead 且混用 → 先纠正口径。  
Behind 才把剩余 + Pace 交给 P05（仍 EP 尺）。

本店含早加价 / 华住分摊 = **NV**。
