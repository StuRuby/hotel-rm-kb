## 0. 一句话

携程 / 美团 / 飞猪 / 同程的促销：**接不接看净贡献和是否打穿 BAR，不看「有没有曝光」。**  
输出只能是 **报 / 不报 / 只报肩日**，并写到 Stay Date。禁止编活动名和佣金%。

完成定义（BACKLOG）：弱日可接、事件日默认拒的日期筛选 + 净价算式（用户给得齐就算，不齐就条件化）。

```
1) 谁出资：店 / 平台 / 共出 / Unknown

## 4. 三选一（禁止「适当参加」）

### 4.1 不报（硬条件，命中任一）

- 该日 Pace Ahead 或 Pickup Fast  
- 已证实 Peak / 压缩 / citywide  
- 店出后公开价 < 新地板（或 < BAR 且不应再降）  
- 连住活动会按弱日价锁 Peak  
- 谁出资不清且店出风险大  

动作：高峰/Ahead 日 **关闭该促销 Rate Plan**（及已有打穿产品）；BAR Open。

### 4.2 报（须同时）

- 出资已知；店出 ≤ 围栏 −3–5% **或** 平台出资且结算不降底价  
- 适用日非 Peak、Pace 非 Ahead、Pickup 非 Fast  
- 净价不打穿地板（缺费率则：店出折扣本身不打穿 + 声明佣金未知）  
- 能设配额（Hypothesis：≤ 剩余 20–30%）与截止日期  

弱日真增量可以留高佣渠道，但净须能算或条件化（净贡献卡 §3）。

### 4.3 只报肩日

Peak 已证实、肩日不热：Peak 不报并关破价；肩日仅当折扣浅或平台出、且**能按日筛选**。不能筛选 = 整段不报，改自有连住包装。

Quota / 截止:        若报：配额 __；活动结束日 __
Do-not-do:
  - 为曝光报高峰
  - 编佣金% / 编活动名
  - 把「不报降权」当 Fact
  - 一夜把 BAR 改成大促价
```

## 6. Trigger

| 事件 | 动作 |
| --- | --- |
| 报了之后 24h Pickup ≥ 阈值高且非一团 | 关新促销或收到 BAR−3%；已降 BAR 不立刻拉回 |
| 48h 仍死 | 不第三刀砸价；改查曝光/产品（问题树 §1.6） |
| 发现适用日其实 Ahead | **立即**关该日计划 |
| 主渠道 BAR 不可订 | 先开 BAR，不重开破价 |
| 用户补出资=平台且结算不降 | 弱日可改「报」 |
| 竞对跟到自杀价 | 不自动跟（P16） |

300 间尺：<3 / 3–7 / ≥8。
