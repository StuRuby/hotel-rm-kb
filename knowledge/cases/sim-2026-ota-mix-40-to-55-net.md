# Simulation Case｜OTA mix 40%→55%，Gross ADR 升、Net 可能降

> 类型：**Simulation / 教学案例，不是真实酒店**  
> 路径：`cases/sim-2026-ota-mix-40-to-55-net.md`  
> 日期：2026-08-21  
> 问：「OTA 从四成到五成五，均价还涨了，是不是该保 OTA？要不要全渠道跟 799，或者干脆关掉 OTA？」  
> 调用：`segmentation/segment-mix.md` · P25 · `steer-mix-by-net.md` · P20  
> 声明：数字为练习数据。佣金 15%、店出 10% **是仿真用户合同**，**不是** 2026 中国 OTA 官方费率。不得写成某家真实酒店结论。标 Hypothesis 的句子不得改成 Fact。不伪造精确增收。

OTB 结构（140 间）：
  Direct / Member  42 间（30%）  Gross ADR 800
  OTA              77 间（55%）  Gross ADR 860

## 1. Intake

口径：Pickup 为间夜。OO=0 Hypothesis。费率 = 用户仿真合同，**禁止**当中国行业%。  
STR ADR 未给，不用 STAR 数当 Gross。

**把 OTB 140 按同结构外推到 STLY 最终 160 间**，只为了和对照比 mix 质量，不是预测（Hypothesis H-extrap）。

| 项 | STLY 已实现 | 9/19 外推到 160（Hypothesis） | 9/19 当前 OTB 140 |
| --- | --- | --- | --- |
| Direct 间夜（%） | 72（45%） | 48（30%） | 42（30%） |
| OTA 间夜（%） | 64（40%） | 88（55%） | 77（55%） |
| Other 间夜（%） | 24（15%） | 24（15%） | 21（15%） |
| Gross ADR | **784** | **818** | 见下 |
| Net ADR（声明成本） | **721** | **689** | 见 §3 |

算术（Simulation）：

```
STLY Gross = (72×780 + 64×820 + 24×700) / 160 = 125440 / 160 = 784
STLY Net   = (72×(780−25) + 64×(820×0.85) + 24×(700−20)) / 160
           = (54360 + 44608 + 16320) / 160 = 115288 / 160 = 721

本期外推 Gross = (48×800 + 88×860 + 24×700) / 160 = 130880 / 160 = 818
本期 OTA Net/间 = 860 − 860×15% − 860×10% = 860 − 129 − 86 = 645
本期外推 Net = (48×(800−25) + 88×645 + 24×(700−20)) / 160
             = (37200 + 56760 + 16320) / 160 = 110280 / 160 = 689
```

OTB 140 已售净（同一费率，不算未来 20 间）：

```
Direct 42×775 = 32550
OTA    77×645 = 49665
Other  21×680 = 14280
已售 Gross = 42×800 + 77×860 + 21×700 = 33600+66220+14700 = 114520 → Gross ADR 818
已售 Net   = 96495 → Net ADR 689
```

与 STLY 同 OCC 比：Gross **+34**，Net **−32**。160 间夜量级净贡献少约 **0.5 万**（仅算术差，**不是**可承诺增收/减收）。

**预选 3 个补数：** OTA 799 产品的适用 Stay Date 清单与出资页；Other 里批发是否开在周六；后 20 间还想卖给谁。

## 2. Situation

200 间仿真店。分析日 8/21。周六 9/19 DTA 29，OTB 70%=140，3D +18，STLY 同 DTA 62% → **Ahead +8pp 且 Fast**。直销可订、899、未倒挂、用户称同步正常。OTA 占比 40%→55%，Gross ADR 784→818，OTA 面价 860>直销 800。OTA 最低可订 799。用户两条指令互斥：跟最低 vs 关 OTA。

---

## 3. Diagnosis

| # | 判定 |
| --- | --- |
| X1 直销没开 | **否**。截图可订 |
| X2 倒挂 | **否**。直销 899 = OTA BAR 层；799 是深折层，不是直销倒挂 |
| X3 不同步 | 用户称没有。Confidence 受口述限制 |
| 口径 | OTA Gross 含佣前；STLY OTA 无 10% 店出。毛净必须拆 |
| 增量 vs 转移 | 总 OCC 对照同为 80% 外推 → **不是弱日增量**。高峰结构从 Direct 45%→30%，OTA 40%→55% = **转移 + 深折** |
| mix 好坏 | B1+B2+B3：OCC 可持平，Gross 升，**Net 降**。变坏 |
| 「OTA ADR 高所以保」 | **拒绝**。OTA Net 645 < Direct 775 < 甚至 STLY OTA 净 697 |
| 799 | 店出 10% 已在 860 层；799 相对直销 BAR 899 约 **−11%**，深于围栏 −3–5%，接近禁止带 |

**主诊断：** Channel Mix 变坏（高峰被更高毛、更低净的 OTA 深折填）。不是直销故障。不是弱日增量。  
**问题树：** §12。  
**不挂：** OCC Low。不因 Gross ADR 升挂 Price Too Low 就保 OTA。

**Pace/Pickup：** Ahead + Fast + Remaining 60。按 3D 日均 6 间，Days-to-Sellout ≈ 10 < DTA 29 → **有 Early Sellout / 压缩倾向**（Hypothesis，衰减未给）。应关低价，不是跟 799。

## 5. Recommended Action

**主动作：不跟 799、不关光 OTA。高峰关 OTA 深折；直销保持 899 可订；BAR 小步上沿，不跳最高。**

```text
Stay Date:            2026-09-19（周六，Peak/压缩倾向）
Room Type:            基础公开房
Direct:               Open。BAR 当前 899
OTA BAR 层（899）:    可订。不平到 799
OTA deep（799 及一切公开 <899）:  今天关
Wholesale 深折:       若 Other 含批发净价开在周六 → 关或限额（用户未切，条件化）
Match lowest:         否
Shut OTA:             否
Price:
  Current BAR:        899
  Recommended Range:  919–939（已在竞对带内且 Ahead+Fast → 档 A +5–8%，但 +5% 已越过最高竞对 939 前须封顶）
  Preferred:          929
  Staging:            一次到 929；不一次跳过 939
  价已最高?:          否（最高竞对 939）→ 允许小涨；若用户已挂 939 则改为只关不涨
Inventory / Quota:    OTA 低价配额 → 0（关 <899）。OTA 899 层保持可订。
                      Hypothesis：不必把 OTA 总配额收到 30–50%，因为问题在深折层不是 BAR 层。
Restriction:          不因 mix 设 MinLOS。若单晚把 9/19 掏空再评 P21；今日无肩日 LOS 表
Promo:                799 出资页未给全文 → 按店出。不报新一层更低活动（P18）
弱日（若用户问 9/15–16 周中）:
                      OTA 围栏 −3–5% 可留；净>0 则留；不一夜 −15%；不关直销
Do-not-do:
  - 全渠道跟 799
  - 关掉 OTA
  - 「OTA 860 高，保 OTA」
  - 一夜 −15% / 把 BAR 砸到 799（约 −11%）
  - 编中国官方佣金%
  - 承诺净增 5008 元（那只是对照算术）
```

决策卡：`steer-mix-by-net.md` + P20 排序。  
不走 do-not-cut（需求不弱）。不走 P18 报名。

---

## 6. Why

**数据：** OTA% 40→55；Gross 784→818；Net 721→689；OTA 净 645 vs Direct 775；DTA29 OTB70% vs STLY62%；3D+18；799 vs 899。  
**逻辑：** 直销开着且平价 → 排除故障。同 OCC 下净掉 → mix 变坏。799 是高峰深折，跟它 = 把所有渠道降到低净地板。关光 OTA 会把 BAR 层增量间夜一起丢掉（未知比例）。Ahead+Fast → 关低价 + 小涨，价不跳最高。  
**Hypothesis：** 外推到 160 间结构不变；3D 速度不衰减则有早售罄倾向。

---

## 7. Expected Impact

- OCC：接受余下 60 间不全靠 OTA 深折填。目标不是用 799 换 80% 满房。  
- Gross ADR：关 799 后新成交 Gross 应靠近 899–929，可能继续升。  
- Net：方向改善（少卖 645 净、多卖 775+ 净）。**不写精确元。** 对照算术 32 元/间 × 余量，只说明量级，不是承诺。  
- Mix：OTA% 可能仍高（BAR 层还在），但深折层应下降。看 **净** 和 **799 是否还在**，不看 OTA% 单一目标。  
- Conversion / 关 OTA 后转移率：Unknown。

## 9. What To Watch / Trigger

```text
1) 未来 24h 净 Pickup ≥ 6 间（对齐 3D 日均）且 799 已关
   → 维持 929 + 直销 Open。不重开深折。

2) 24h Pickup 塌 <3 间 且 直销仍可订平价 且 799 已关
   → 不降 BAR。OTA 899 层确认可订。仍不跟 799。
   若确认其实是弱日误判 → 离开高峰逻辑，评围栏 −3–5%（预付 869–879），BAR 仍 929。

3) 直销突然不可订或价 > OTA BAR
   → 停 mix 战略，只修供给。

4) 竞对集体到 799
   → 不自动跟。挂 P16。本店深折仍关。

5) 用户补「平台出且结算不降」
   → 高峰仍不把直销对齐 799；肩日/弱日可重评报名。
```

## 10. Confidence

方向（不跟 799、不关光 OTA、关深折、直销 Open）：**Medium**。  
929 点：**Medium-Low**（档 A 被最高竞对封顶，首选对齐 929 是 Hypothesis）。

Evidence：机制 A（毛≠净）；动作 B/Hypothesis。
