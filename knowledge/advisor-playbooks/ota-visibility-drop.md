## 0. 一句话

排名掉了：**先查库存、比价、内容，不要先砍 BAR。**  
为曝光去报深折：**走 P18**（谁出资、净价、砸不砸高峰）。排名 FOMO 不是开门条件。  
平台算法不编。没有截图证据 **只给检查单**，不给「权重公式」。

完成定义（BACKLOG）：能区分关库存 / 价倒挂 / 内容评分 / 没参加曝光位 / 真没需求 / 周末玄学；输出先修可观察项，而不是无条件接促销。

顾问必须能直接说的三句：

```
1. 排名掉了先查库存、比价、内容，不要先砍 BAR。
2. 为了排名去报深折，走 P18：谁出资、净价、砸不砸高峰。
3. 平台算法不编；没有截图证据只给检查单，不给「权重公式」。
```

独立默认（本库 Hypothesis，待真实反馈）：OTA 搜索位次是 **黑盒**。顾问能修的是 **可观察故障**（关着、价明显出局、内容缺、被筛掉）和 **P18 闸后的报名**。不能修的是「权重公式」。Booking / Expedia 公开页只作 **诊断清单来源**，禁止抄成美团/携程 SOP。

## 2. 输入（缺截图不停，但不编公式）

```
必须：
1) Stay Date + DTA（到小时，若当晚）+ Pace / Pickup
2) 当前公开 BAR（直销 + OTA BAR 层）与全渠道最低可订
3) 该渠道该日库存是否开：rooms to sell / 配额 / 限制（MinLOS、CTA、CTD）
4) 「排名掉了」的证据形态：截图 / 后台曝光点击 / 纯口述

应用：
5) 竞对同日可订价（决定价是否真出局，不决定权重）
6) 点评分 / 近窗差评 / 主图与设施是否过期（用户能给的程度）
7) 是否有促销/投放邀约：活动在用户后台的原名、谁出资

Recommended：
8) 直销是否可订、渠道是否同步（P25）
9) 用户合同佣金 / 加佣（有则算净；无则 Unknown，不编 %）
10) 变动成本三数（T19）；没有不得说深折总比空着强
```

**独立店默认：** 开口问「哪个平台、搜什么关键词/日期、有没有后台曝光图、主房型今晚开着吗？」用户说不清 → **只出检查单**，Confidence Low。禁止根据「感觉掉到第 8 页」发明权重。

缺佣金%、缺算法、缺截图 **不停**：用条件句。Unknown 算法 → 不给公式。Unknown 出资 → 深折默认不报（P18）。

## 3. 先排除

| # | 排除 | 成立时 |
| --- | --- | --- |
| X1 | 该 Stay Date 主房型/该渠道库存 = 0，或配额 0，或 ARI 不同步 | **先开库存**。不降 BAR。见 `open-inventory-false-low-occ.md` |
| X2 | MinLOS / CTA / CTD 把目标搜索挡掉 | 评 **P33**：先松限制，不要先降 BAR |
| X3 | 主 BAR / 直销其实关着，只剩深折能订 | 先开 BAR（P25），**不**用深折换曝光 |
| X4 | 公开可订并未明显高于全部竞对（价差 <8% 且 Pace 不差） | **禁止**为排名砍 BAR。P16 不跟 |
| X5 | 价已最高且 Pace Ahead / 已证实 Peak | 只关不涨；**不报名**换排名（P18 S2/S4） |
| X6 | 市场也空 / 天气交通停 | **do-not-cut**（P02/P28）。排名不是需求真空的药 |
| X7 | 差评潮 / 主图差 / 设施未填 / 信息过期 | **修内容**。不砍 BAR |
| X8 | 出资 Unknown 且折扣看起来店出 > 围栏 −5% | **不报**（P18）。要合同 |
| X9 | DTA≤3 想一夜把 BAR 改成 −15% 大促 | 走 **P05**。禁止一夜 −15% 永久化 |
| X10 | 净价会穿用户贡献（或成本 Unknown 却要配已知深折） | **T19** 关该产品。不为 OCC/排名卖穿底 |

排除顺序：X1 库存 → X2 限制 → X3 主 BAR 关着 → X7 内容 → X4/X5 价 → X6 市场 → X8/X9/X10 促销与贡献。

## 4. 诊断枝（先诊断，禁止「为排名先砍 BAR」）

```
用户说排名/曝光掉了、流量没了
│
├─ 0. 证据？
│     有后台曝光/点击/搜索位截图，写明日期与关键词
│           → 当输入，仍不编权重
│     纯口述 / 销售话术
│           → 只给检查单。Confidence Low。不给「权重公式」
│
├─ 1. 库存关了？
│     主房型该渠道 rooms=0 / 配额 0 / 渠道经理不同步
│           → 开库存。假曝光故障
│     限制把该次搜索拿掉（Booking 公开说：限制可让你不出现）
│           → P33，先松
│
├─ 2. 价比隔壁高很多 / 倒挂？
│     公开可订 >> 全部竞对（Hypothesis ≥8–15%）且 Pace 真落后且市场不冰
│           → 先围栏 −3–5%（档 E），不是 BAR −15%
│           → DTA≤3 走 P05 三档，仍禁一夜永久 −15%
│     房型/渠道倒挂（P34）
│           → 先修倒挂
│     价已可比 / 价已最高
│           → 不砍。查 1 / 3 / 5
│
├─ 3. 评分或内容？
│     主图差、设施未勾、描述过期、近窗差评未回
│           → 修内容/回复。HSMAI：完整度影响 OTA 位次
│     Booking 公开：筛选匹配靠设施声明；照片是搜索第一印象
│           → 仅 Booking 机制旁证，不抄成美团公式
│
├─ 4. 没参加曝光位 / 付费槽？
│     后台邀约、优待、今夜特价、投放
│           → **P18**：谁出资、净价、Peak？
│           → 排名 FOMO / 「不报降权」= NV，不当门
│     高峰 / Ahead / 出资 Unknown 深折
│           → 不报。关打穿计划
│
├─ 5. 真需求没了？
│     市场/竞对同样空、事件取消、天气
│           → P02 do-not-cut / P28 Soft OTB。不是算法
│     市场不空、只有本店流量掉
│           → 份额/分销故障（回 1–4），不是「没人出门」
│
└─ 6. 周末算法玄学
      同一城市同一晚，不同账号看到不同顺序（Booking FAQ：因人而异）
      DOW / 周末筛选 / 本地 vs 外地客
      无后台证据 → Hypothesis。禁止把「周六掉了」写成必须砸价
      顾问动作：检查单走完；BAR 默认 Hold

Naive（禁止）
      「排名掉了所以 BAR −15%」
      「报今夜特价就能回第一屏」（无出资、无净价）
      「不报一定降权」（NV）
      「美团权重：价格 40% 内容 30%…」（编造）
      「佣金加到 X% 就能买排名」（无合同原文）
      「为曝光开盲盒」（P27 高峰关）
```

**与 P18：** 本剧回答「要不要为排名动」。一旦动作是报名，**整段移交 P18**。本剧不另发明活动名。

**与 P05：** 当晚空房先排除关库存/内容。P05 默认 6h **保持或认栽**。排名掉了 **不是** 档 H 的开门条件。档 H 仍须价明显高于全部 **且** 市场不冰 **且** 贡献不穿。

**与 P20：** 用加佣/投放换位次要算净。缺费率不算假精确净额；结构上「为排名加佣」常劣于开库存/修内容。

**与 P16：** 竞对更便宜或「他们报了所以我们要报」= 价格战叙事。Pace 不差且价差 <8% → 不跟。排名恐慌按价格战处理：**不跟到底**。

**与 T19：** 今夜特价净价不得穿贡献。没成本不得说深折总比空着强。

**与 P27：** 不为排名新开盲盒。高峰 Ahead 仍关 opaque。

## 5. 十步过程（顾问内部，可对用户压缩）

```text
1. 映射 Stay Date × 平台 × 「掉了」的证据（截图/口述）× DTA × Pace/Pickup。
2. 查库存：该日主房型该渠道是否可订、配额、ARI 同步。关着 → 开，停价。
3. 查限制：MinLOS/CTA 是否把目标 LOS/到达挡掉。过严 → P33。
4. 比价：直销 vs OTA BAR vs 全渠道最低 vs 竞对可订。倒挂先修（P34）。
5. 内容/评分：主图、设施勾选、近窗差评。缺则修，不砍 BAR。
6. 市场：竞对是否同样空、是否天气/事件。市场冰 → do-not-cut。
7. 邀约：有促销/投放则整段 P18（谁出资、净、Peak、能否按日关）。
   排名 FOMO 不是报的理由。不报降权 = NV。
8. 价动作：默认 Hold。仅当 X4 不成立（价真出局）且非 Peak
   → 围栏 −3–5%；DTA≤3 → P05 三档。禁止一夜 BAR −15%。
   价已最高只关不涨。
9. 贡献闸：任何新低价层过 T19。穿底关产品。P20 比净。
10. 输出检查单 + 区间/首选 + 再要 3 个数 + Trigger。
    不输出权重公式。无截图则声明 Hypothesis / Low confidence。
```

## 6. 动作（必须落到 Stay Date / 先修哪一项）

```text
Stay Date / DTA:
Platform:            用户原名（顾问不发明活动名）
Evidence:            截图 | 后台曝光 | 口述-only
Inventory:           OPEN 误关房型/渠道；限制过严 → 评松（P33）
Content:             主图/设施/差评回复（用户运营做；顾问不代操作）
Public BAR:          默认 Hold；区间+首选
Fence:               仅价真出局且市场不冰 → −3–5% 有截止
Promo:               移交 P18 → 报 | 不报 | 只报肩日
Last-minute:         P05 三档；6h 默认保持/认栽
Contribution:        穿底不卖（T19）
Do-not-do:
  - 先砍 BAR 救排名
  - 一夜 −15% 当新 BAR
  - 编权重表 / 编佣金% / 编活动名
  - 把「不报降权」当 Fact
  - 为排名开盲盒或砸高峰
```

工作锚（仿真尺度，约 180 间）：周六当晚 BAR 799、竞对 749–829、主房型美团关着、排名纯口述 → **先开库存**；公开 **779–799 首选 799**；今夜特价出资 Unknown → **不报**。不要 679。

## 7. Trigger

| 事件 | 动作 |
| --- | --- |
| 开库存后 6–12h 仍 0 且价已可比且市场空 | **认栽/Hold**，不第三刀砸价 |
| 开库存后 Pickup 回来 | 维持 Hold；不补报深折 |
| 用户补出资=平台且结算不降、日期非 Peak | 弱日可改交 P18「报」 |
| 价差拉开 ≥8–15% 且 Pace 转落后且市场不冰 | 档 E 围栏；仍禁一夜 −15% |
| 发现其实 Ahead / Peak | 立即关破价；不报名 |
| 用户补截图显示只是千人千面 | 降为玄学枝；BAR 不动 |
| 战术净价穿贡献 | 关该层（T19） |

## 8. 如果只能再补 3 个

1. 该渠道该日 **库存是否开** + 主图/限制截图（翻转「假曝光」）。  
2. **谁出资** + 店出折扣（翻转报/不报）。  
3. 同日 **竞对可订价** + 近窗 Pickup（翻转要不要围栏，而不是砍 BAR）。

## 9. Confidence / 边界

有库存+比价+Pace：方向 Medium。纯口述排名：方向仍可给检查单，**公式与幅度 Low**。  
Booking 五要素 / Expedia Offer Strength = **该平台 Vendor**，抄到美团/携程 = 降为 Hypothesis 清单，不当 Fact。  
中国四平台酒店搜索权重、不报降权、佣金%：**NV**。
