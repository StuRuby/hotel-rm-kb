## 0. 一句话

取消异常 → OTB 含金量下降。先问为什么，再改预付结构 / 停涨 / 评超售。  
**禁止把 OTB% 当硬需求。** 「正常」用本店同政策历史，不报行业取消率。

完成定义（BACKLOG）：「正常」的定量替代；取消高时禁止硬 OTB%。

---

## 1. 信号

进入：取消间夜明显啃掉净 Pickup，或用户说「订了又取消」。

| # | 信号 |
| --- | --- |
| K1 | 某窗（24h/7D）取消 ≥ 新订，净 Pickup ≤0 |
| K2 | 取消 / 期初 OTB 明显高于**本店**同 DOW、同政策、同 DTA 窗 |
| K3 | 刚涨价后取消跳，且再订落到更低公开价 |
| K4 | 灵活价取消高、预付几乎不取消（结构差，不是「全店病」） |

**不是本剧本：** 一团洗房 → Group。事件取消/天气 → 先当需求消失（P02/P07 退出），本篇管政策层。只要超几间 → `overbook-or-not`。

## 2. 先排除（先诊断枝）

| # | 排除 | 成立时 |
| --- | --- | --- |
| E1 | 分母：用了询单/未确认 | 先改口径 |
| E2 | 改期被算成取消+新订 | 看净占用，不看毛取消 |
| E3 | 一次性能源：一笔团、一次航班、一场演出取消 | 不当政策病；停涨，解开事件价 |
| E4 | 拿灵活价取消率和预付比 | 无意义；拆开看 |
| E5 | 政策刚收紧：取消降但转化也降 | 不是全面胜利 |
| E6 | 基线内波动（相对本店史，不是相对博客） | **什么都不动** |

「正常」替代（Hypothesis，不是行业%）：

```
正常 ≈ 本店同 DOW × 同取消政策 × 同 DTA 窗 的历史取消/OTB
没有历史 → 不报数字；只比 预付 vs 灵活 结构，标 Unknown
博客「OTA 免费取消 50–60%」= C，不采用
```

软 OTB（顾问内部，有史才算）：

```
SoftOTB ≈ OTB × (1 − 期望剩余取消率)
期望剩余取消率 用本店同窗历史；无史 → 只定性：「OTB 偏软，不按硬需求涨」
```

---

## 3. 诊断落格

| 主机制 | 证据 | 动作 |
| --- | --- | --- |
| 政策过松 + 价高占位 | 灵活占比高；取消后再订更低价 | 压缩日缩短免费取消窗 / 提高预付占比（P19，折仍 ≤5% 第一刀）；**不**用更深折扣锁单 |
| 涨价副作用 | 取消紧跟涨价刀 | 停第二刀；已涨不立刻拉回；关仍开着的更低公开入口 |
| 事件/天气取消潮 | 外部旗标 + 多渠道同时取消 | 回到平日带；**禁止**在取消潮中大涨或加大超售 |
| 渠道质量 | 单渠道取消畸高 | 收该渠道灵活配额；不道德关光 |
| 质量/口碑 | 差评、事故 | 运营优先；降价是止血 |
| 基线内 | 相对本店史不显著 | 不动 |

不推荐（问题树 §10）：用更深折扣「锁单」却不改政策 — 可能吸引更多占位客。

## 4. 动作表

```text
Stay Date:
Cancel 24h / 7D vs 新订:
政策结构:     灵活 __% / 预付 __%
相对本店史:   高 / 基线 / Unknown
OTB:          当 Soft（不按硬需求涨）
Decision:
  政策松+占位     → 压缩日收紧免费窗；弱日开 AP −3–5%（P19）
  刚涨价引发      → 停涨；关破价
  事件取消        → 回平日带；停超
  要超售          → 有史才给方向；无史不给间数
Do-not-do:
  - 用 OTB 70% 当 Ahead 再涨
  - 报「行业取消率 20%」
  - 加深折扣当锁单
  - 无史「超 5%」
```

超售：取消**升高**不是自动多超。历史失效（刚涨价、事件潮）→ 停超或收到 0–下限（超售框架 §3.1）。预付已主导 → No-show 近 0，默认不超。

## 5. Trigger

| 事件 | 动作 |
| --- | --- |
| 24h 取消回落到本店史 | OTB 可重新当硬信号 |
| 收紧政策后转化塌、市场不冰 | 弱日解开免费窗，不砸 BAR |
| 取消翻倍或 ≥ 总房 2%（与 MinLOS 卡同一惊醒尺） | 停加严限制 / 停涨 |
| 预付占比升、取消降 | 守新结构；高峰仍关深折 AP |
