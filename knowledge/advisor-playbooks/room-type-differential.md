## 0. 一句话

同一 Stay Date，更高档公开可订价 **≤ 更低档**，或差过小到免费升、过大到高档死。当天修阶梯。禁止倒挂当促销。

完成定义：全房型卖价 + 库存 + 升级路径 → 抬低档或收高档的信号。

与 P13 的差别：P13 是「一型先穿」的库存问题；本篇是 **价梯病**。两病可同时：先修倒挂，再按 P13 保护穿的那型。

---

## 1. 信号

| # | 信号 | 病 |
| --- | --- | --- |
| I1 | 高档公开价 ≤ 低档（早餐/取消口径对齐后） | **倒挂** |
| I2 | 差 <5% 或 <30 元，且常免费升 | **过小** |
| I3 | 高档 Pickup≈0，差 >30%（Deluxe）或套房长期 0 + 免费升 | **过大** |
| I4 | Base 将穿 + 阶梯仍倒挂 | 先本篇，再 P13 |

名称（Superior / Deluxe）无法定阶梯，读本店价单（房型差卡 §1）。

## 2. 先排除

| # | 排除 | 成立时 |
| --- | --- | --- |
| E1 | 渠道映射错（Deluxe 卖成 Base 价） | 只修映射，不当「策略倒挂」 |

---

## 3. 路径（与修倒挂卡同一套）

| 路径 | 信号 | 动作 |
| --- | --- | --- |
| **抬低档** | 压缩 / Pace Ahead / Base 将穿 / 倒挂 | 低档收到恢复阶梯；高档不降或略抬；停免费升 |
| **收高档** | 弱市、高档空、低档价已最高 | 高档 −5–10% 收入带（不一夜 −15%）；**Base 不降** |
| **只对齐** | 仅单渠道倒挂 | 全渠道拉到同一梯子，不改结构价 |

差价讨论带（Hypothesis，房型差卡 §2）：Superior +8–15%；Deluxe +15–25%；Exec +20–35%；Suite +40–80%。给不出点 → 区间+首选。博客「升级价=差的 30–50%」= C，**高峰不采用**。

价已最高只关不涨：倒挂时「抬低档」= 涨 Base，须确认 Base 尚未最高；已最高则关低档破价、修映射，不把高档再抬出市场。

---

## 4. 动作表

```text
Stay Date:
当前梯子:   Base __ / Sup __ / Dlxe __ / Exec __ / Suite __
建议梯子:   区间 + 首选（房型差卡 §2）
路径:       抬低档 / 收高档 / 只对齐
Inventory:  穿的那型关低入口；高档 Open
Channel:    全渠道对齐
Do-not-do:  倒挂拉曝光；降高档填总 OCC；未知结构动套房
```

例（Simulation）：Base 799、Deluxe 759 → 倒挂。Ahead：Base 799–859 首选 829，Deluxe ≥899。
