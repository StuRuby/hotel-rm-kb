## 0. 一句话

P06 的中国特化：**春运窗口 ≠ 放假 9 天**；春节必须农历/STLY；探亲店与旅游店高峰对倒；连住长度常比国庆长，但 **禁止** 9 天同一 MinLOS。

完成定义：能输出春节/国庆整段形状，并写清与 P06/P21 的差异。

## 1. 与 P06 / P21 的差异（必须先读）

| 维 | P06 / P21 通用 | 本篇加上 |
| --- | --- | --- |
| 日历 | 法定假 + 调休 | **春运**另有 40 天窗口，覆盖出城/返程，不只放假那几天 |
| 对照年 | 节日对齐 STLY | 春节**禁止**公历 LY（2025 春节 ≠ 2026-02-15 对 2025-02-15） |
| 客群 | 「节假日休闲」一筐 | **探亲 / 返乡 / 旅游 / 留守商务** 四条，店型决定哪几天 Peak |
| 连住 | MinLOS=2 只盖已证实 Peak | 春节探亲 LOS 常更长（讨论锚 3–7 晚，Hypothesis）；仍只盖已证实 Peak，先 =2，连续 ≥3 夜高峰才评 =3 |
| 调休 | 假周五/假周中按上班 | 春节前后两个补班周六（2026：2/14、2/28）按**上班日**，不当周末 |
| 交通 | 一般信号 | 春运票务热是 **Lead Time 信号**，不是酒店 OCC 门槛。人次数字不当阈值 |

复用：按日画形状、Peak 关低价、肩日 Open、价已最高只关不涨、档 B/C 幅度。不重写 T1–T12。

## 4. 连住（相对 P21 的增量）

| 场景 | MinLOS | 禁止 |
| --- | --- | --- |
| 国庆已证实 1–3 夜高峰 | =2 只盖那些夜；肩日 Open | 10/1–10/7 同一 N |
| 春节探亲店，连续 ≥3 夜都热 | 先 =2；48h 仍过快再评 =3 | **9 天 MinLOS=3/5/7** |
| 春节旅游店，仅初三–初五热 | 只盖那几夜 =2 | 除夕–初七全盖 |
| 春运出城/返程单日交通峰 | 通常 **不** 设节日 MinLOS | 把春运 40 天当一节 |
| 调休上班日 | 不设节日 MinLOS | 当周末 |

春节探亲 LOS 更长是 **客群事实讨论锚**（Hypothesis），不是自动把 N 设成 5。自然连住已经 4 晚时，MinLOS=2 几乎不挡人；真正要防的是 **旅游店被单晚切初三**。

折扣连住：Peak 不再给深折；肩日围栏 −3–5%。套均价不打穿 Peak 新地板（P21）。

## 5. 动作表

```text
节:                 春节 | 国庆
店型:               探亲/老家 | 旅游目的地 | 一线商务 | 枢纽返程
对照:               农历 STLY / 去年该节（禁止公历 LY 对春节）
Peak 夜:            <列出，须有 Pace/Pickup/历史/竞对 之一>
MinLOS:             只盖 Peak；默认 =2；连续 ≥3 才评 =3
Shoulder / 春运头尾: Open；不自动节日价
调休上班:           周中逻辑
Price:              与 P06 同一档；无旁证不吃「春节」故事
AP/NR / 大促:       Peak 关深折（P19/P18）
Do-not-do:
  - 春节套公历 LY
  - 9 天或 7 天同一 MinLOS
  - 春运人次当满房阈值
  - 空城商务店按景区涨
```

幅度：走 `how-much-to-move.md`。节假日只加 Urgency，不自动加大第一刀。价已最高只关不涨。

## 6. Trigger

| 事件 | 动作 |
| --- | --- |
| 24h 该 Peak Pickup < 阈值低 | 解开该日新 MinLOS；价回下限 |
| 节中已过 Peak（如初六旅游店空、国庆 10/6 返程弱） | 解开节日限制，回平日/肩日带 |
| 天气/运力中断取消升 | 停涨；OTB 改软（P14） |
| 一团占位造成假 Ahead | 停散客加码 |
| 2/28、10/10 仍挂节日价 | **立即**改上班日带 |

300 间尺：<3 / 3–7 / ≥8。
