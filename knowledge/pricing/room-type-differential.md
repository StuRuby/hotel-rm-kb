## 0. 一句话

房型差是 **同一 Stay Date 上，更高价值房型相对 Base 应收的价差**。差太小 → 免费升级、高档白送；差太大或倒挂 → 高档卖不动 / 低档被掏空。名称（Superior / Deluxe）**没有行业法定阶梯**，以本店产品清单和价格单为准。

```
价（BAR）     = 保留价格
房型差        = 谁愿意为更好的一间多付
库存          = 哪一型还卖、穿了怎么走升级
```

未知房型：只动 BAR / 基础售卖房，套房差价今天不动（与过程文件、Protect 卡一致）。

## 1. 梯子（本店自己定义）

顾问默认口语梯子（**命名惯例，不是官方标准**）：

```
Base / Standard  →  Superior  →  Deluxe  →  Executive  →  Suite
```

| 档 | 通常多什么 | 注意 |
| --- | --- | --- |
| Base | 入门可售 | 价格锚 |
| Superior | 楼层 / 景观 / 略大 | 少数店把 Superior 放 Deluxe 之上，**先读本店房价表** |
| Deluxe | 面积/装修/卫浴更明显 | 仍是单间，不是套房 |
| Executive | 行政酒廊/楼层/待遇 | 差价含服务，不只房间 |
| Suite | 起居与卧室分隔 | 用「分隔」定义，不用面积口号 |

公开说明「名称无外部定义、以价单为准」：Octorate 房型解释页（**C Vendor**，2026-08-20 检索）。本库采用其**方法**（看本店价单），不采用其 % 表当 Fact。

## 2. 差价启发式（Hypothesis，待 feedback）

没有本店弹性，不得 High。下列是 **讨论锚**，须与产品可见差异、竞对对应产品对齐。

| 相对 Base | 第一刀讨论带 | 过小（信号） | 过大（信号） |
| --- | --- | --- | --- |
| Superior | **+8–15%** 或 +50–150 元（取更贴该店价位） | <5% 或 <30 元，且常免费升 | 无可见差异却 >20% |
| Deluxe | **+15–25%** | 与 Superior 只差 20–30 元 | >30% 且 Pickup≈0 |
| Executive | **+20–35%**（含酒廊则靠上沿） | 酒廊开放却不收费差 | 商务淡日仍挂周末差 |
| Suite | **+40–80%** | 与 Deluxe 只差一档预付 | 长期 0 Pickup + 免费升 |

数字与 BAR 第一刀 +8–15% **同尺巧合**：Superior 第一档用同一百分比带，便于执行，不是理论最优。套房不要跟 Base 同一晚 +8–15% 就当「已经拉开」。

**给不出点：** 区间 + 首选；首选取带中偏低（涨差）或中偏高（收差）。

竞对锚：对齐**同一物理档**（大床/景观/行政），不要拿人家套房比自己 Base。

## 3. 四种病

### 3.1 倒挂（Inversion）

更高档 **公开可订价 ≤ 更低档**（含早餐/取消口径对齐后）。

动作：当天修。见 `fix-room-type-inversion.md`。

```
先抬低档 或 先降？  
  压缩 / Pace Ahead / 低档快穿 → 抬低档到恢复阶梯（优先），高档不降
  高档长期空、市场也弱、低档价已最高 → 高档小步降到阶梯内，低档不降
禁止：用倒挂当曝光促销
```

### 3.2 差过小

升级转化≈100% 免费或「补 20 元就上 Deluxe」。ADR 结构被摊平。

动作：拉开到 §2 带；压缩日禁止免费升级（除非运营补偿 OOO）。

### 3.3 差过大

高档 Pickup≈0，Base 将穿，前台只能免费升。表面「套房 OCC 低」其实是价差病。

动作：先确认图文/库存开着（问题树 §11 先排除）。开着则收高档差到带内，**Base 不降**。

### 3.4 房型压缩（Compression）

Base Days-to-Sellout ≤3，高档仍厚。

动作（与 inventory-control / P09 一致）：

```
涨/关 Base 低入口；高档不降来「平衡 OCC」
价已最高：只关 Base 低价，不涨
可开付费升级（Upsell），不要免费把高档填满
```

---

## 4. Upsell

| 何时 | 怎么定价（Hypothesis） |
| --- | --- |
| Base 将穿、高档有剩 | 升级价 = 公开差的一部分，但 **压缩日不要低于公开差的 70%**（避免自砸阶梯） |
| 弱日、高档空 | 可把升级价收到公开差的 40–60%，BAR 阶梯本身不动 |
| 已免费升成习惯 | 先停免费，再谈付费 |

公开博客有「升级价 = 公开差的 30–50%」（BookingWhizz 等，**C**）。本库 **不采用为高峰规则**；弱日可当讨论锚并标 C。高峰按公开差卖。

---

## 5. 与已有启发式兼容

- 未知房型：只动 BAR/Base。  
- 全型都快：全店关低价 + BAR 第一刀；套房涨幅 **不超过** Base 第一刀百分比。  
- 价已最高只关不涨：倒挂时「抬低档」等于涨 Base，须确认 Base 尚未最高；已最高则关低档破价、修映射。  
- 不一夜 −15%：修过大差价时高档第一刀不要砸 15%+。  
- Peak MinLOS：限制按到达日，通常全型一致；不要只对 Base 设 MinLOS 把单晚全赶到 Suite。
