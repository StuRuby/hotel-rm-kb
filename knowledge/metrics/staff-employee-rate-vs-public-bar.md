# Metric｜Staff / Employee Rate vs Public BAR（轻）

> 路径：`metrics/staff-employee-rate-vs-public-bar.md`  
> 配：P80  
> 状态：drafted 2026-08-30 10:17  
> **无默认员工折扣 %、无「员工必须打 X 折」、无「员工住满 = 必须砍 BAR」、无配额 Fact**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 员工价 / 付费员工折扣挂牌（用户给；不编）
- 分层（能拆就拆；拆不清标 NV）：
  1. 公开灵活 BAR（non-qualified, publicly available）
  2. 付费员工折扣码（OPERA 例：STAFF；可按 Times Sold 关）
  3. $0 员工 complimentary / House Use（STR 历史 Sold Exclude；过程走 P47）
  4. 员工旅居资格闸（AHLA 项目页证明存在；% 不进 Fact）
- gap = 公开 BAR − 员工价（只观察，不推导必须折扣）
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成员工地板 / 员工价太低所以跟 / 员工住满了所以砍 / OCC·ADR 被员工看脏所以砍」

## 不用来做什么

- 不推导「员工该打几折 / 每天该放几间」
- 不把员工价 / 付费员工折扣写成公开 BAR
- 不因「员工价太低 / 员工住满了 / OCC 被员工撑满 / ADR 被员工折扣看脏」自动砍公开尺
- 不把 OPERA Vendor Times Sold=3、AHLA 40%+ 写成中国店规或默认 %
- 不发明员工折扣 % / 配额 Fact
- 不把 P23 会员、P47 $0 Comp/HU 当成「本店必须改 BAR」

## STR / OPERA 拆（读法不是改尺令）

| 层 | 上报 / 系统 | 对公开 BAR |
| --- | --- | --- |
| 付费员工折扣码 | 有房价的资格码；可进 Rooms Sold（有收入） | ≠ BAR Type |
| $0 员工 Comp / HU | STR 历史 Sold **Exclude**（无关 complimentary） | ≠ BAR；过程走 P47 |
| STAFF Times Sold 关码 | OPERA 策略闸 | 关码 ≠ 改写公开尺 |
| Comp / House Use 勾选 | 统计跟踪 | ≠ BAR Type |

OCC「被员工撑满」、ADR「被员工折扣看脏」：**都是读桶，不是砍尺。**

## 调用

早会/调价前看：公开 BAR；员工价是否被当成尺；有没有人要求 BAR→员工地板；OCC/ADR 是否被员工「看满/看脏」却想砍尺。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁员工借口一夜 −15%；围栏须有截止日）。

本店员工价 SOP / 华住字段 = **NV**。
