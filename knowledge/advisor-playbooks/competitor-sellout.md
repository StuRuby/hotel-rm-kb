## 0. 一句话

竞对满房是 Compression **强信号**，仍要核自身剩余与是否可比。完成定义：**1 家满 vs ≥2–3 家满** 不同动作；套不可比则退出。

## 2. 先排除

| # | 排除 | 成立 |
| --- | --- | --- |
| X1 | 满的是 Aspirational / 不可比 | 退出 |
| X2 | 只是某 OTA 配额满 | 不当溢出 |
| X3 | Pickup 是一团 | 停散客加码 |
| X4 | 自身价已最高、低价已关 | 只盯不涨 |
| X5 | 自身渠道关着、看起来「还有房其实卖不了」 | 先开 |

---

## 3. 动作（1 家 vs 多家）

| 满房数 | 本店状态 | 第一刀 |
| --- | --- | --- |
| **1 家 Primary** | Pace On、Remaining 厚 | **不自动涨**；关明显破价；盯 24h |
| **1 家** | Ahead+Fast 或价低 ≥8% | 档 A/B 下沿：+5–10% 或收到最低**仍可订**竞对 |
| **≥2 家** | 任一 Pace/Pickup 旁证 | 当弱 citywide：关低价 + 档 B（+8–15%），不跳最高 |
| **≥3 家** | Fast | 走 `citywide-compression.md`；允许 +15–20% 仍 ≤ 原最高 |
| 任意 | 价已最高 | **只关不涨** |

先后：先关低价，再涨。MinLOS=2 只盖已证实 Peak + 肩日有数。

---

## 4. Trigger

| 事件 | 动作 |
| --- | --- |
| 满房店重新开出且降 | 停加码，不跟降 |
| 24h Pickup <3 | 回退下限 |
| 24h ≥8 非一团 | 第二刀 +3–8% |
| 发现不可比 | 撤回事件/溢出幅度 |

2. 本店 Remaining + 3D Pickup。  
3. 有无匹配事件。
