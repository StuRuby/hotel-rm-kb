> **无默认溢出折扣 %、无「必须比姐妹店便宜 X」、无区域统价 Fact %、无佣金%**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 姐妹店挂牌 / 拟议溢出价（用户给；不编）
- gap = 本店 BAR − 姐妹店挂牌（只观察，不推导必须折扣）
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「按她们价接 / 统最低 / 帮空店先砍」

## 不用来做什么

- 不推导「溢出该便宜多少」
- 不把姐妹店挂牌写成公开 BAR
- 不因「集团导过来」自动砍/涨
- 不把 Duetto / OPERA 例示写成中国 Fact
- 不发明区域统价 % / 佣金%

## 调用

早会/调价前看：本店公开 BAR；姐妹店挂牌是否被当成尺；有没有人要求 399 接或统最低。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁溢出借口一夜 −15%）。

本店 cluster / 华住字段 / 默认溢出折扣 = **NV**。
