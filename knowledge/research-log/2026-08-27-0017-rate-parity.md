## 3. 卡立了什么（一句话 + 五点）

**一句话：** 自家某一渠道比 Brand.com 便宜之后，这把尺只允许改诊断，不允许自动改 Brand.com BAR。

1. **价平是同一酒店可比公开报价的关系，不是 Comp Set 价。** 第一闸是产品身份（房型、取消、早餐、税、登录/会员、日期）。对不上 → shop-comparability（P36），不是破平。隔壁店便宜走 P16/P36，不走本卡。
2. **围栏不是破平。** 会员 / 预付 / 打包 / 切房 / 协议价设计上就可以低于灵活公开 BAR。把它们叫「破平」等于拆掉围栏（P23/P19/P27/P26/P58）。HSMAI 把 Rate Fences 放在 Rate Parity 相邻词条。
3. **毛价平 ≠ 净贡献。** 把 Brand.com 砍到 OTA undercut 可以净更差。费率 NV，不编佣金%。结构走 P20 / T19。
4. **修的方向是便宜侧或映射，不是自动 Brand.com dump。** HSMAI Narrow：合同限制的是官网不得低于该 OTA。OTA 已经更便宜 → 不是典型的酒店侧窄条款违约形态；是分销完整事故候选（错促销 / CM 映射 / 展示）。今夜 Brand.com 仍只由公开 Pace 开门。
5. **管辖 + 假尺子一族。** Booking no/narrow/wide 按国（§40）；EEA DMA = EEA 管辖标签，不是中国规则；本店条款 NV。T-Parity 与 T-Share（RGI≠BAR）/ T-Reputation（评分≠弹性）/ T-Guar（混合 OTB≠已卖）同族：尺子 ≠ 按钮。七问全部 NV，本卡不代答。
