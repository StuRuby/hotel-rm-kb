## 证据（本轮打开）

- Oracle OPERA Cloud · *About Best Available Rates*（A Vendor PMS，打开）：BAR = 某日某房型最低合格公开价模型（by Day / by LOS / Best BAR by Day）。**是房型定价模型，不是「含餐套餐总价 = BAR」。**
- Oracle OPERA Cloud 25.2 · *Package Codes*（A Vendor PMS，打开）：allowance 包元素 Item Price **从房价金额扣减** → nett accommodation = rate − Σ item price。例：套餐 $540，餐+酒后住宿净 $370。**套餐挂牌 ≠ 全部是房费；餐有独立分摊。**
- OnlineHotelier · *Hotel Rate Plans: EP, CP, MAP, AP*（C 实践，打开）：**BAR 起点 = EP（裸房）**；CP/MAP/AP 加在 EP 之上；OTA 应用 EP 作 base 参与比价。印卢比例 **不进中国 Fact**；60–80% 早餐加价 **不进默认店规**。
- Prostay *Hotel Breakfast Guide 2026*（C，curl 打开）：room-only 与 breakfast-included **分价码**；差价可见。€/美元 8–15 价差 **不进中国 Fact**。
