## 0. 一句话

**错推低价不是市场价格。** 线上 399 若来自错映射 / 错价码 / 忘关促销 / 测试价上线，它不证明那晚需求在 399 出清，也不是把 Brand.com 和其他渠道「对齐到现实」的理由。先确认是不是本打算卖的；是错价就先停错码、修映射；Hold 意图 BAR。已出去的错价单问本店政策（NV）。修好后再按真 Pace 走 P01 或 P05。Hold 意图 BAR 779–799 首选 799（Hypothesis / Simulation）。本店 CM 字段名 / 美团映射 SOP = **NV，不编**。

完成定义：一张「先问是不是本打算卖的 → 停错码/修映射 → 已订错价问本店（NV）→ 剩余库存按意图 BAR + Pace 重打分」过程。七种假信号写进**同一本**剧本：

| 形 | 看起来 | 实际 | 默认动作 |
| --- | --- | --- | --- |
| **A 错价当市价** | 「已经卖了 399，市场就是这个价」 | 错推 / 错映射；不是需求出清 | **禁止当清市场价。** Hold 意图 BAR |
| **B 破平假警报** | 「美团比官网便宜，破平了要跟」 | 便宜侧是错误码，不是故意 undercut | **P60** 先隔离错码；不要走 P59 的「修便宜侧=对齐辩论」 |
| **C 不可比假警报** | 截图看起来房型/含早对不上 | 可能是映射把标准房推成了别的产品 | 先核映射；确认不可比 → **P36**；确认错推 → 本剧 |
| **D 促销忘关** | 「美团在做活动」 | 过期/测试促销仍开，不是 P18 报名 | **关错开促销**；报名闸仍 P18 |
| **E 前台要跟** | 「客人拿着 399 截图，前台跟不跟」 | 错价不是前台口价 | **P42**：前台别跟错价 |
| **F 弱夜借口** | 「399 进得快，说明该夜该砸」 | 错价成交不是 Pace 信号 | 修好后按意图 BAR + 真 Pace 走 **P01/P05** |
| **G 误入** | 竞对更低 / 房型倒挂 / 切房卖不掉 / 真破平 | 别的剧本 | **P16** / **P34** / **P58** / **P59** |

顾问必须能直接说的三句（与决策卡同一套，不另发明）：

```
1. 先问线上这个价是不是 **本打算卖的**（房型码、价格码、促销开关、CM 映射）。错推/错映射不是需求信号，也不是该改 Brand.com 的理由。本店 CM 字段名 / 美团映射 SOP = **NV**，不编。
2. 先停错码、修映射，再谈价。Hold 意图 BAR 779–799 首选 799（Hypothesis / Simulation）。不要为了「已经挂出去了」把官网也砍到错误价。
3. 已出去的错价订单怎么处理问本店政策（NV），不在顾问剧本里编退改表。错价修好后按真 Pace 走 P01 或 P05。真破平走 P59；不可比走 P36；前台别跟错价走 P42。不要把 BAR dump 到 399「先跟再改」。
```

独立默认（本库 Hypothesis）：错误价 **不是** 市场出清价，也 **不是** 新的公开 BAR 地板。SiteMinder Help（A Vendor CM，§42）：平台房型价与渠道房型价是**一一映射**；断映射只停平台侧更新，渠道侧该价仍可卖，须在渠道 extranet 关/删。这是**厂商能力事实**，不是美团/华住映射 SOP，不是本店字段名。缺本店 CM 字段 / 映射表 → **问，不编**。

尺（Hypothesis；14/399/799 只 Simulation）：意图 BAR **Hold 779–799 首选 799**。禁止因错价去 dump Brand.com。禁止 BAR→399。禁止一夜 −15%。14 / 399 / 799 **只允许出现在 Simulation**，不是行情 Fact。**399 = 错误价，同时是被拒绝的 dump，不是推荐 BAR。**

Vendor 指针，不在本剧重写成中国 SOP：

- SiteMinder Help Platform *Map your room rates to a channel*（A Vendor CM，§42）：映射 = 平台 room rate ↔ 渠道 room rate；每条渠道价型须映射到**一条**平台价；断映射 ≠ 渠道下架；未映射/错配可超卖或漏单。UI 字段名是该厂商的，**不是**本店/美团字段。
- SiteMinder 营销页 *Channel mapping*、Cloudbeds Advanced Channel Rates：本轮 Cloudflare 拦 → **不当核页**。

本店 CM 字段名 / 美团映射 SOP / 华住映射 SOP / 佣金% = **全部 NV**。

## 1. Situation

钉 **两条价**：①本打算卖的公开灵活 BAR（意图 BAR / 正确房型码+价格码）；②线上某渠看到的活价（具名 OTA 或 Brand.com 误挂）。不要把错价写成「市场价」。

先问（缺则标 NV，不停）：

- 线上这个价是不是 **本打算卖的**（房型码、价格码、促销开关、CM 映射）
- 意图 BAR 是多少；活价是多少；是否同一取消/含早/税口径
- 错的是 **映射**（标准大床 → 错码）、**价码本身**、**促销忘关**，还是 **测试价上线**
- 错价已经卖出几单（若知）；本店对错价单的政策 = **NV**
- 当前公开 Pace（Ahead / On / Behind）；remaining
- 用户原话是想 **官网跟到 399**、**先跟再改**，还是想关错码 / 修映射
- 本店 CM 字段名 / 美团映射表 = **NV**（有截图则用户读；无则不编）

用户原话包括：「CM 把标准房推成了 399」「映射错了美团在卖错房型价」「错价已经出去了官网要不要跟」「先跟再改回来」「已经卖了不能破平 / 不能装没看见」。

本店 CM 字段 / 美团映射 SOP / 华住 SOP / 退改表 = **全部 NV**。

## 2. Diagnosis

对焦点 Stay Date 走「是不是本打算卖的」，再打错价轴：

| # | 检查 | 用来回答 |
| --- | --- | --- |
| D1 | 活价对应的房型码 / 价格码是否等于意图产品 | 否 → 错映射 / 错码候选 |
| D2 | 促销开关是否本打算开 | 否 → 形 D；关错开；不是 P18 报名 |
| D3 | 取消 / 含早 / 税是否与意图 BAR 同一口径 | 否且不是映射问题 → P36 |
| D4 | 便宜侧是本店错推，还是竞对 | 竞对 → P16 |
| D5 | 是否房型梯故意倒挂 | 故意梯 → P34；映射事故 → 本剧 |
| D6 | 是否切房桶 / 配额 | 切房 → P58 |
| D7 | 用户要不要把 Brand.com 砍到活价「对齐 / 先跟」 | 是 → 形 A/G；禁止 |
| D8 | 已订错价单数量 / 本店政策 | 问（NV）；不编退改 |
| D9 | 公开 Pace / remaining（按意图 BAR 口径） | Ahead → P01 Hold；真弱才 P05，理由写需求不是「错价已经出去」 |
| D10 | 前台是否要跟 399 截图 | 是 → P42；前台别跟错价 |

真实酒店若当前意图 BAR 不在该带，保留 **Hold 方向**，不把 779–799 当市场 Fact。

早会带走一个动作（P45）：通常是 **「先关错码 / 修映射，公开 BAR Hold」**，不要 **「全网对齐到 399」**。不要两刀同时（又砍官网又修映射）。

顾问对 GM / 电商三句回话：

> 「先问线上这个价是不是本打算卖的。错推不是需求，也不是改官网的理由。」
> 「先停错码、修映射。官网 Hold 在 779–799，首选 799。不要因为已经挂出去了就砍到错误价。」
> 「已订错价单问本店政策。修好后按真 Pace。不要先跟再改。」

## 5. Why

1. **用了哪些数据（Fact）：** SiteMinder Help：房型价须映射到渠道房型价；断映射只停平台更新，渠道侧仍可卖（A Vendor CM，§42）。本店字段 / 美团 SOP = 用户给或 NV。意图 BAR 与活价 = 用户截图。
2. **逻辑链：**
```text
错价 = 分销完整事故，不是需求曲线上的一点
+ 399 被当成市价 → 把事故写成定价输入（形 A）
+ Brand.com 跟到 bug → 训练购物者/算法：399 是真价；再拉回会掉进 rate-recovery 坑
+ 「破平」喊声若来自错码 → 路由 P60，不是 P59 的对齐辩论
+ 修好后剩余库存仍只由意图 BAR × 该夜 Pace 开门（P01/P05）
+ 已订错价单 = 履约/客诉/法律问题，顾问不编退改表
```
3. **理论 / 卡：** T-Parity 尺不是按钮；P59 真破平修便宜侧；P36 可比性；`how-much-to-move.md` 禁一夜 −15%；P01 公开 Ahead Hold。
4. **哪一句是 Hypothesis：** 779–799 / 首选 799；「错价不是清市场价」方向 Hypothesis；无弹性系数；无中国映射 SOP Fact。

## 6. Expected Impact

| 指标 | 必须回答 |
| --- | --- |
| OCC / 最终售出间夜 | 关错码不承诺直销立刻补量。已订错价锁价；未订的错价应停 |
| ADR | Hold 意图 BAR 保护增量 ADR。砍到 399 压每一间后续公开成交 |
| RevPAR | Hold 路径随 ADR；对齐砍价可能 OCC 微升、RevPAR 不升。不编精确增收 |
| Pickup | 分渠道：错码关掉后该渠错价成交应停；Brand.com 看直销净增 |
| Conversion | Unknown。不编点击率 |
| Net Revenue | 把官网砍到错价可能恶化直销净（P20）。费率 NV 不算假精确净额 |
| Profit | Unknown。不编 GOP / Walk $ |

允许的写法：若 24h 内错码收回且意图 BAR Hold、Pace 仍 Ahead → Hold 成立。若公开真 Behind 且厚 → 再评 P05，理由写该夜需求，不写「错价已经出去了」。
