## 0. 一句话

距离入住还远就已经接近满，或按当前速度会在 DTA 一半之前满，且成交/在售价偏低。目标是 **ADR 和尾部结构**，不是再冲 OCC。  
完成定义：能回答「现在 85%、DTA 21，该不该继续卖 799」。

---

## 1. 信号

DTA 通常 **≥8**（更短走 P03 / 到达日超售）。任 2 条、来自不同家族：

| # | 家族 | 信号（Hypothesis） | 300 间例 |
| --- | --- | --- | --- |
| E1 | 时间 | 满房或 OTB ≥80–85% 时的 DTA **长于** 该店历史满房 DTA | 历史 DTA 5 才满，现在 DTA 21 已 85% |
| E2 | 速度 | 中位 Days-to-Sellout（日均×0.7）< DTA × 0.5 | 剩 45、日均 6 → 中位 10.7；0.5×21=10.5 |
| E3 | 价格 | 成交 ADR 或在售最低价明显低于 BAR/竞对；低价产品仍开 | 还在卖 799，竞对 899+ |
| E4 | 结构 | 高价值房型已空、Base 被低价铺满 | 套房 0，Base 预付仍开 |
| E5 | 历史 | 该类日最终 ADR 应高于当前 OTB ADR，且去年不是这么早满 | STLY 最终更高 |

**「现在 85%、DTA 21、还卖 799」→ 进本剧本（默认不要继续卖 799）。**

**不是 Early Sellout（退出）：**

- 度假/节前历史就是 DTA 20 满，且当前 ADR 已在带上沿 → 可能只是正常曲线（仍要看价）。  
- 「满」只是某渠道配额。  
- 一团占位，散客其实不热。  
- 价已最高 + 低价已关 + 只是 OCC 高 → 只留尾、不涨（价已最高只关不涨）。

## 2. 先排除

| # | 排除 | 成立时 |
| --- | --- | --- |
| X1 | 历史该 DTA 本来就满 | 仍核 ADR；价对则只留尾不涨 |
| X2 | 渠道假满 | 开 BAR 层；不是早售罄 |
| X3 | 一团 / 重导 | 按散客剩余重算；转 P10 |
| X4 | 超售未计入，实际还有 wash | 先还原真剩余 |
| X5 | 已满日事后想「补卖」 | 已发生只能复盘；**不事后降价**。动作在相邻日+取消替换价 |

---

## 3. 动作（先后强制）

与 P03 同一把尺，但触发更早、更满：

```
第 0 步  真满还是渠道满（X2）
第 1 步  今天关公开可订 < 新地板（不等 OCC 到 90%）
第 2 步  价未最高 → 第一刀 +8–15% 或收到最低竞对，不一次跳最高
          价已最高 → 只关 / 收限额 / 评 MinLOS，不涨
第 3 步  留尾：Remaining 的 20–30%，首选 25%；或按历史最后 3 日 Pickup
第 4 步  Peak+肩日齐 → MinLOS=2 只盖 Peak；肩日 Open
第 5 步  不关 BAR；不把剩余锁 0
第 6 步  已满日：取消替换价 ≥ 新 BAR；评超售只给方向（无取消史不给间数）
```

### 3.1 「85% / DTA 21 / 799」默认输出

假设 300 间：OTB 255，剩 45。竞对未知时用百分比档。

```
Stay Date:            该日
不要：                继续卖 799
关:                   一切公开可订 < 新地板
BAR:                  799 → 859–919，首选 879（+10%，档 B）
                      若最低竞对 ≥899 → 重叠带到 899–919，首选 899
                      若 799 已 ≥ 全部可比竞对 → 不涨，只关破价
尾部:                 留 9–14 间（20–30%×45），首选 11 间给 DTA≤3
Restriction:          无肩日今天不设 MinLOS
Channel:              拒会打穿地板的促销
Do-not-do:            庆祝 85%；再开预付；第一刀到最高竞对之上
```

有竞对必须重算重叠带（`how-much-to-move.md`）。

### 3.2 第二 / 第三刀（本剧本要补的）

| 刀 | 何时 | 做什么 |
| --- | --- | --- |
| 第一 | 今天 | 关低价 + 档 B/C |
| 第二 | 24h Pickup ≥ 阈值高且非一团、竞对未降 | BAR 再 +3–8%，仍不跳过原最高竞对 |
| 第三 | 仅当竞对再涨或 ≥2 家满 **且** 剩余仍按中位会在 DTA 一半前没 | 可靠近原最高竞对；**无新信号禁止第三刀** |
| 关房 | 某型 Days-to-Sellout ≤3 | 该型只留直销/升级，不关全店 BAR |

价已最高：没有第二刀涨价，只有再收限额。

---

## 4. Trigger

```
24h 净 Pickup < 3（300 间）     → 回到第一刀下限；不重开破价
24h 3–7                         → 守关低价 + 当前 BAR
24h ≥8 且非一团、竞对未降       → 第二刀 +3–8%
取消 ≥ 总房 2% 或翻倍           → 停加码；超售只给方向
发现 Pickup 是一团              → 撤回第二刀；BAR 上限第一刀下限；转 P10
剩余 ≤ 尾部预留                 → 停卖低档；只开 BAR/直销
竞对降到我们新价下              → 不自动跟到底；守地板
已满日后取消                    → 替换价 ≥ 新 BAR，不按旧 799 重开
```

---

## 5. 如果只能再补 3 个

1. 历史该日满房时的 DTA + 最终 ADR（判断是不是「本来就早满」）  
2. 在售最低价列表 + 分房型剩余  
3. 7D Pickup 是否大单  

---

## 6. Confidence / 边界

方向：DTA 长 + 已高 OCC + 价低 → Medium 偏 High。  
「过早」的历史对照缺了 → 幅度 Medium，可能其实是度假正常曲线。  
P03 管更近的危险；P05 Last Minute 管 DTA 极短仍剩。P21/P29 节假日细则未写：节假日早满仍先走本篇关+涨，MinLOS 交给已有卡。
