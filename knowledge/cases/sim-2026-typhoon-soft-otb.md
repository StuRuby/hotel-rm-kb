# Simulation Case｜台风取消潮：OTB 高但不该涨（Soft OTB）

> 类型：**Simulation / 教学案例，不是真实酒店**  
> 路径：`cases/sim-2026-typhoon-soft-otb.md`  
> 日期：2026-08-21 22:17 CST  
> 天气旗标：**Simulation**。虚构店、虚构预警。**不点名假台风当 Fact**；不把 NMC 公报里的编号风暴写成这家店的路径  
> 组合：取消潮 + OTB 看起来高 + 用户要涨/砸/超  
> 用途：检验「OTB 还很高要不要涨？取消潮里能不能降？要不要超售？」→ **停涨、Hold、停超、天气夜 Open 限制**  
> 调用：`advisor-playbooks/weather-disruption.md` · `recommendations/dont-raise-into-cancel-wave.md` · `treat-otb-as-soft.md` · P02 `do-not-cut` · P24 停超 · P33 先松限制  
> 不要把下列数字写成某家真实酒店或某场真实台风结论。

## 2. Situation

180 间沿海休闲仿真店。Stay Date 8 月 22 日周六，分析夜 DTA 1。OTB 82%=148 间，剩余 32 间。近 24h 取消 18、新订 4、净 −14。BAR 999，竞对 969/999/1029。MinLOS=2 仍开。用户称预警 + 机场高铁大面积取消，想涨到 1199，或降到 799 填洞，或再超 8 间。STLY 无天气同 DTA 68%。昨日预警前 OTB 88%。无本店取消史、无 Walk 成本。

## 3. Diagnosis

| # | 判定 |
| --- | --- |
| D1 | 天气旗标 + 取消≥新订 → **进 P28**，不是普通周末高峰。 |
| D2 | 交通大面积取消：优先态 **A 消灭 / B 平移**。滞留未证实（不是机场店）。 |
| D3 | OTB 82% vs STLY 68% 是 **假 Ahead**：24h 净 −14，含金量掉。**Soft**（P14）。 |
| D4 | 对照物：无天气 STLY 68%/BAR~899，不是昨日 88%。昨日 88% 是风暴前幻想水位（P32 表亲）。 |
| D5 | BAR 999 相对可订竞对 +3%，**不是显著价高**。1199 是涨进取消潮。799 是 −20%，破一夜 −15%。 |
| D6 | 取消史刚坏（且无史）→ **停超**，不给「8 间」。 |
| D7 | MinLOS=2 在交通不稳夜可能挡住改期短住 → **先 Open**（P33），不要先砸 BAR。 |
| D8 | 市场冰（进不来）→ `do-not-cut`。32 间剩余不是 P05「价贵所以没卖掉」的默认。 |
| D9 | Forecast 若仍按 88% 高峰 → P17 事件错，先改 overlay。 |

## 4. Recommended Action

**Decision：不涨、不降到 799、不停超以外的加超、天气夜 Open MinLOS。BAR Hold 969–999，首选 999。**

| 杠杆 | 动作 |
| --- | --- |
| 定价 | **Hold 969–999 首选 999**。拒绝 1199。拒绝 799。不报围栏：价已在带内 + 市场冰。 |
| 库存 | 主 BAR 可订。虚假 OTB 等客人取消后再卖；不要把未取消当空房去超。 |
| 超售 | **停加超**。不给 8 间。无史不给精确间夜。若今晚已超 → 转 P24 停接。 |
| 限制 | **Open** 8/22 MinLOS（天气夜）。不要整周拆掉以后的已证实 Peak。 |
| 预测 | overlay 回到无天气周六，不追 88%。 |
| 渠道 | 不报当晚大促填坑。改期优先于加深折扣锁单。佣金% NV。 |

## 5. 拒绝项（为什么那三句是错的）

| 用户方案 | 为什么拒 |
| --- | --- |
| 涨到 1199 | OTB Soft；交通可能消灭需求；+20% 一天跳档；价已不低。**取消潮中不涨。** |
| 降到 799 | −20% 破一夜 −15%；市场冰弹性可能极差；价相对竞对并不显著高。填坑砸价。 |
| 再超 8 间 | 取消史刚坏 + 无史。**不给精确超售间夜。** |

## 6. Expected Impact / Risk / Watch

- **Impact：** 方向是保护 ADR 与避免 Walk，不是当晚 OCC 最大化。定量收入 **不报**（仿真也无弹性点）。  
- **Risk：** 若其实是机场滞留店，Hold 可能少接 walk-in —— 本仿真不是机场店；若用户补 walk-in 升，改态 D，价仍稳、库存仍开。若交通其实没停、取消只是噪声，Hold 可能少收一档 —— 用 24h Trigger 回看。  
- **Watch：** 24h 取消 vs 新订；交通公告；相邻 8/23 是否平移；RevPAR 若有人已先砍一刀。  
- **Confidence：** 停涨/停超/拒 799 = Medium。首选 999 vs 969 = Hypothesis（差 30 元，带内）。

## 7. 兼容性检查

- 围栏 −3–5% / BAR −5–10% / 禁一夜 −15%：本晚不进降价档。  
- 无取消史不给精确超售间夜：遵守。  
- OTB 高取消 = Soft：遵守。  
- 价已最高只关不涨：本晚未到「已最高」，但是取消潮停涨。  
- Diagnose before action：四态先于价。
