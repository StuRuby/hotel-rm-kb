## 0. 一句话

全市压缩 ≠ 单店事件 ≠ **mega-event 虚火**。  
官宣和大馆不能单独定义 citywide。先问 **Pace 是否坐实**、**肩日有没有被带动**。比赛 / 开展夜可涨（走事件第一刀）；肩日 **不要自动跟 Peak**。Pace 落后于「事件叙事」时走 P17 + 弱市不降价，**禁止从幻想价砍到仍贵**。对照物是 **去年无事件基线**，不是事件价。

完成定义：三形态检查单 + 按日动作（Peak / 肩日 / 虚火回落）+ 明确禁止整周涨、禁止 1999→1299。

成功标准：用户说「全市演唱会 / 展会 / 大赛，要不要整周涨、卖不动再从 1999 砍到 1299」→ 本剧：先问 Pace / 肩日，拒绝从幻想价回落。

## 1. 信号

进入：用户在用「全城 / 大赛 / 世界杯级 / 会展周 / 多馆叠日」论证 **整周涨价**，或事后要从高位公开回落。

| # | 家族 | 问 |
| --- | --- | --- |
| C1 | 官宣 | 官方日期、场馆、是否已取消 / 缩规模 / 退合同房块 |
| C2 | 距离 | 本店到场馆。远 → 更像无关或虚火，不按 citywide |
| C3 | 竞对 | Primary **是否真关 / 满**，还是只有媒体说「全城涨」 |
| C4 | Pace | 该日 vs **无事件 STLY/曲线** 是否真 Ahead？vs **事件 overlay 预测** 是否 Behind？**两套对照必须拆开** |
| C5 | Pickup | 3D/7D 是否动；是否一团 / 退块回流 |
| C6 | 肩日 | ±1 / 非比赛夜是否也被带动，还是只有叙事在涨 |

**三种形态（必须先选一，禁止混用动作）：**

| 形态 | 识别 | 走哪 |
| --- | --- | --- |
| **真全市压缩** | ≥2 家 Primary 满或市场紧 **+** 本店 Pace Ahead 或 Pickup Fast **+** 日期匹配 | 已有城市卡：关低价 + 档 B |
| **单店事件** | 场馆近、overnight 成立，但城市未紧（<2 家满、无本店 Ahead） | **离开本剧** → P07 / P22 |
| **mega-event 虚火** | 叙事强、价已抬，但 OTB/Pickup 落后于事件预测；或相对无事件基线并不 Ahead；肩日无回填；国际客 / 团队退块 / 短租分流 | P17 事件错 overlay + 本剧虚火枝 + `dont-cut-from-hype-rate.md` |

STR Glossary **无** Compression Night 词条（城市卡已写，2026-08-20）。实践「市场 OCC>90%」= B，中国无公开逐日市场 OCC 时 **不要编 90%**，用竞对满房计数。

## 2. 先排除（没过不许整周涨，也不许从高位砍）

| # | 排除 | 成立时 |
| --- | --- | --- |
| E1 | **只有媒体叙事，没有 Pickup / Pace 旁证** | 不挂 citywide；不整周涨；最多关破价 |
| E2 | **国际客 / 团队退合同房块**（组委会退块、签证、长途成本） | OTB 当 Soft；停散客加码；先改 Forecast（P17） |
| E3 | **短租已分流价格敏感客** | 酒店剩的是「付得起事件价」的窄需求；降到「仍贵」填不满 → 虚火枝，不按弱日砸 BAR |
| E4 | 只有 1 家满 / Comp 不可比 | P15 弱版，不叫 citywide |
| E5 | 旗标无 overnight / 场馆远 | P07 退出 |
| E6 | Pickup 是一团包房 | P10；停散客加码 |
| E7 | 价已最高且低价已关 | 只盯，不涨 |
| E8 | 把 Budget / 事件幻想预测叫 Forecast | P17：不追错目标 |
| E9 | 3D 快 7D 不快 | 24h 只关破价，不设 MinLOS、不加第二刀 |

E1 / E2 / E3 任一条成立：**默认不是「再涨一点」或「从幻想价砍到仍贵」。**

## 3. 诊断落格

| 结论 | 识别 | 第一工具 |
| --- | --- | --- |
| 真压缩，比赛 / 开展夜 | C3 + C4 Ahead + 日期匹配 | 事件第一刀；关低价；评 Peak MinLOS=2 |
| 真压缩，肩日也被 Ahead | 肩日 **自己的** Pace/Pickup Ahead | 肩日半档或收到最低竞对；**不挂 Peak 价** |
| 真压缩，肩日未被带动 | 肩日 On/Behind | **肩日不要自动跟 Peak**；Open + 连住包装 |
| 单店事件 | 城市未紧 | 离开本剧，P07 / P22 |
| 虚火：叙事 Ahead、Pace Behind | 对照无事件基线并不 Ahead，只对照幻想预测才「落后」 | **先改判断**（P17）；BAR 按无事件带 Hold |
| 虚火且已挂幻想价、现在卖不动 | 公开价远高于无事件竞对 / STLY，Pickup 死 | `dont-cut-from-hype-rate.md`：**禁止 1999→1299** |
| 假问题 | 后置曲线 / 一团未到 | Hold |

### 3.1 案例（C/B，**不作 S**，**不改第一刀幅度**）

2026 世界杯主办城市预售 / 热身窗，行业媒体转述 STR/CoStar 样本 + AHLA pulse（Hotels Experience，2026-07-13，本库 2026-08-21 打开）：

| 窗口 | 媒体转述 | 对本库的含义 |
| --- | --- | --- |
| 比赛夜 | ADR +25–30%、OCC 0～+2pts、RevPAR +18–22% | 高 ADR 可以发生在 OCC 几乎不动时。**不**把 +25–30% 写成默认第一刀 |
| 肩日 | ADR +10–15%、OCC −3～−5pts | **压缩没有自动回填肩日**。肩日跟涨可能只抬价、掉 OCC |
| 叙事 | 「不要当成 104 场超级碗」 | 禁止「有大事件就全市涨、肩日自动被带动」 |

短租分流价格敏感客、FIFA 退合同房块、签证 / 长途成本使国际客不到预测：写入 **机制假说**（与 E2/E3 同向），不当本店数字。

InnBrief 评论（C/D）：AHLA「80% 低于预测」、从幻想价砍到「仍然很贵」仍挡替代需求、Rate Recovery Trap。**禁止**把 80%、$800、$1300 当本库事实。可用机制：对照无事件基线，不要对照事件价做回落。

## 4. 动作表

### 4.1 按日，不要整周一个价

**Peak（比赛夜 / 开展夜）** — 须 Pace 或 Pickup 或竞对满 **之一** 旁证：

| 杠杆 | 动作 |
| --- | --- |
| 价 | 事件第一刀：**+8–15%** 或收到最低仍可订竞对；**不跳最高**。价已最高 **只关不涨**。仅旗标无旁证 → 档 A，幅度不吃大赛故事 |
| 库存 | 今天关公开 < 新地板；BAR Open。Sellout 先关低价 |
| 限制 | overnight 已证实 **且** 肩日有数 → Peak **MinLOS=2**；否则今天不设 |
| 渠道 | 拒打穿新 BAR 的 OTA 大促 |
| 团 | 低价只要 Peak 单晚 → Counter（P10） |

**肩日（非比赛 / 非开展，或 ±1）：**

| 杠杆 | 动作 |
| --- | --- |
| 价 | **不要自动跟 Peak**。IF 该日自己 Ahead THEN 半档；ELSE Hold + 连住包装 |
| 库存 | 主渠道 **开**；不要按高峰关促销层（浅围栏可留） |
| 限制 | **肩日 Open**。不 MinLOS / 不 CTA |
| 渠道 | 只报肩日走 P18；Peak 大促不报 |

**虚火日（叙事有、相对无事件基线并不 Ahead）：**

| 杠杆 | 动作 |
| --- | --- |
| 判断 | 先改 Forecast overlay（P17 事件错）。对照 **无事件 STLY / 无事件竞对**，不对照事件幻想预测 |
| 价 | 守无事件基线带；**禁止**从幻想价砍到中间「仍贵」价（见决策卡） |
| 市场也空 | 弱市不降价：公开 BAR 不再砸；弹性可能很差 |
| 限制 | 解开误伤肩日；未证实 Peak 不要留 MinLOS=2 |
| 库存 | 主 BAR 可订；不把「回落」当成打开残价层 |

### 4.2 合并输出

```text
Stay Date:            按日（Peak / 肩日 / 虚火日 分开写）
形态:                  全市压缩 / 单店事件 / mega-event 虚火
对照:                  (a) 无事件 STLY/基线   (b) 事件 overlay 预测 — 必须拆开
Peak price:           事件第一刀 Range + 首选；不跳最高；价已最高只关不涨
Shoulder price:       不自动跟 Peak；半档或 Hold
Hype recovery:        禁止从幻想价砍到仍贵；对照无事件基线
MinLOS:               只盖已证实 Peak =2；肩日 Open
Do-not-do:
  - 有大事件就全市涨、肩日自动被带动
  - 整周一个事件价
  - 只有媒体叙事就当 Compression Fact
  - 从 1999 砍到 1299（Rate Recovery Trap）
  - 一夜 −15%
  - 把 80% / $800 / $1300 / ADR+25–30% 当本库事实或默认幅度
```

### 4.3 启发式兼容（本轮不改数字）

```
涨 +8–15% 或收到最低竞对；一天不跳最高；价已最高只关不涨
MinLOS=2 只盖已证实 Peak；肩日 Open
降：先围栏 −3–5%；BAR −5–10%；禁止一夜 −15%
弱市不降；不跟自杀价
本剧第一刀是「形态」：真压缩才涨 Peak；虚火先改判断
```

## 5. Trigger

| 事件 | 动作 |
| --- | --- |
| Peak 24h Pickup <3（300 间尺） | 回退下限；核是否虚火 |
| Peak 24h ≥8 非一团且竞对仍满 | 第二刀 +3–8%，仍 ≤ 原最高可比 |
| 肩日仍 0 / Behind | 确认 Open；**不把 Peak 价延过去** |
| 肩日自己 Fast | 肩日改半档，停肩日大促 |
| 组委会退块 / 签证 / 国际客不到 | 立刻改 overlay；OTB 当 Soft；停加码 |
| 事件取消 / 缩规模 | **立即**回无事件带 |
| 已挂幻想价、想公开砍到中间价 | 走 `dont-cut-from-hype-rate.md`；禁止 1999→1299 |
| 竞对重新开房并降到我们新价下 | 停加码；不自动跟降 |

## 6. 如果只能再补 3 个

1. 本店该日 OTB + 3D Pickup，以及对照的是 **无事件 STLY** 还是 **事件预测**（翻转 citywide vs 虚火）。  
2. 几家 Primary 满 / 是否仍可订。  
3. 肩日 ±1 的 OTB（有没有被带动）。

缺 1：不整周涨，不叫 citywide。  
缺 3：肩日今天不跟 Peak、不设 MinLOS。

## 7. Confidence / 边界

真压缩 + 本店旁证：方向 Medium；幅度 Hypothesis。  
只有叙事：方向 Low，只关破价。  
虚火回落：方向 Medium（禁止幻想价回落）；落到哪条无事件带 = Hypothesis。

更像单场演唱会 → P07。  
更像会展布撤展 → P22。  
更像 1 家满 → P15。  
更像周末无大赛 → P11。  
更像预测假设错 → P17。  
更像市场冰点（无事件）→ P02 `do-not-cut-price-market-also-weak.md`。

数字边界：世界杯表内数字 = 案例 **C/B**，禁止升 S，禁止改 +8–15% 尺。InnBrief 80% / $800 / $1300 = **C/D**，禁止当本库事实。
