# Metric｜BRG Claim vs Public BAR（轻）

> 路径：`metrics/brg-claim-vs-public-bar.md`  
> 配：P75  
> 状态：drafted 2026-08-29 14:17  
> **无默认赔付 %、无「被索赔必须跟」、无「截图 = 验证」、无佣金%**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 索赔/比价挂牌（用户给；不编）
- gap = 公开 BAR − 索赔挂牌（只观察，不推导必须折扣）
- 是否已在直销渠道订出
- like-for-like：同店 / 同房型 / 同取消 / 同含早 / 同人数 / 非券后 / 非打包 / 非 opaque / 非协议
- 本店是否声明有最低价保证（是 / 否 / Unknown）
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成索赔价 / 跟全网最低」

## 不用来做什么

- 不推导「贵就赔该赔多少」
- 不把索赔匹配价写成公开 BAR
- 不因「被索赔了 / 截图便宜」自动砍公开尺
- 不把万豪 25% / 5,000 分、希尔顿 25% extra 写成中国 Fact 或独立店 SOP
- 不发明赔付% / 佣金% / 华住字段

## 调用

早会/调价前看：公开 BAR；索赔是否被当成尺；有没有人要求 BAR→截图价。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁索赔借口一夜 −15%；围栏须有截止日）。

本店贵就赔 SOP / 华住字段 = **NV**。
