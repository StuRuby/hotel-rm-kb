## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- Extra Adult / Extra Child / Occupant Threshold / 加床加项挂牌或该笔加额（用户给；不编）
- gap = 客人看到的「含加项总价」− 公开单人/双人 BAR（只观察，不推导必须折扣）
- 是否价码日价表加项 / 超人数阈值固定额（能拆就拆；拆不清标 NV）
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成三人地板 / 加床太贵所以跟 / ADR 被污染所以砍」

## 不用来做什么

- 不推导「第三人该加多少 / 儿童该收多少」
- 不把 Extra Person / 加床加项写成公开 BAR
- 不因「三人住太贵 / 加床拉高均价 / 儿童加床污染 ADR」自动砍公开尺
- 不把 OPERA Vendor $ 例、HFP Net 实务句写成中国店规或默认 %
- 不发明 Extra Person % / 儿童费 Fact

## 调用

早会/调价前看：公开 BAR；加项是否被当成尺；有没有人要求 BAR→三人地板；ADR 是否被加项「看脏」却想砍尺。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁加床借口一夜 −15%；围栏须有截止日）。

本店加床/儿童 SOP / 华住字段 = **NV**。
