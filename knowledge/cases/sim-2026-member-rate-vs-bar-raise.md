# Simulation Case｜BAR 已涨、会员滞后：跟 / 冻 / 部分跟

> 类型：**Simulation / 教学案例，不是真实酒店**  
> 路径：`cases/sim-2026-member-rate-vs-bar-raise.md`  
> 日期：2026-08-21  
> 问：「BAR 要涨，会员价跟不跟、跟多少？会员已经比 OTA 还高/低怎么办？」  
> 调用：P23 · `follow-or-hold-member-rate.md` · `how-much-to-move.md` · P18 · P25  
> 声明：200 间店与下列价格均为 **练习数据**。不得写成某家真实酒店结论。标 Hypothesis 的句子不得改成 Fact。不伪造精确增收。不把万豪 2%/5% 写成该店义务。

## 0. 用户原始输入（仿真）

```text
酒店：200 间（Simulation，中国大陆独立店，无品牌会籍合同）
分析日：2026-08-21
用户原话：「周六 BAR 已经从 849 提到 899 了，会员还挂 849。下一步还要不要再涨 BAR？会员跟不跟？销售说会员必须永远便宜 10%，不然没人办卡。OTA 上有 799，有人说会员 849 已经比 OTA 贵了。」

Stay Date：2026-09-12（周六）
DTA：22
OTB：72% = 144 间
3D Pickup：+21 间
STLY 同 DTA：62%
公开 BAR（直销 + OTA BAR 层）：899
会员价（微信/官网登录可见）：849（用户确认要登录；未登录展示 899）
OTA BAR 层：899
OTA 可订最低：799（预付/店出活动，出资页未给全文）
竞对可订：929 / 949 / 979
直销官网/微信未登录：用户截图可订、899，库存与 OTA 同房型
渠道同步：用户说「BAR 层没问题」
品牌会籍规则：无。「我们自己发会员，没有万豪/希尔顿义务折扣。」

OTB 结构（144 间）：
  Direct / Member  50 间（35%）  其中 Member 计划 32 间
  OTA              72 间（50%）
  Other            22 间（15%）
```

## 1. Intake

口径：Pickup 为间夜。OO=0 Hypothesis。无品牌义务 → **酒店自有围栏**。  
799 单列深折层，不与 899 BAR 层混比。  
「会员必须便宜 10%」= 用户口述，**不是**本库 Fact。

四价：

| 层 | 现行 |
| --- | --- |
| 公开 BAR | 899 |
| 会员（封闭） | 849（相对 BAR −5.6%，差 50 元） |
| OTA BAR 层 | 899 |
| OTA 深折 | 799（相对 BAR −11.1%） |

会员 849 **低于** OTA 公开 899，**高于** OTA 深折 799。  
所以：「会员比 OTA 贵」这句话 **只在拿 799 比时成立**——比的是深折层，不是公开 BAR 层。

**预选 3 个补数：** 799 适用日与出资；会员计划是否真的登录墙；后 56 间还想卖给谁。

## 2. Situation

200 间仿真独立店。分析日 8/21。周六 9/12 DTA 22，OTB 72%=144，3D +21，STLY 同 DTA 62% → **Ahead +10pp 且 Fast**。公开 BAR 已从 849 提到 899，会员未跟、仍 849。竞对 929/949/979。用户同时问跟不跟、10% 义务、以及 849 vs 799。

---

## 3. Diagnosis

| # | 判定 |
| --- | --- |
| 品牌规则 | **无** → 自有围栏。禁止把「必须 10%」或万豪 2%/5% 写成该店义务 |
| X2 直销故障 | **否**。未登录 899 可订 |
| 枝 b 倒挂 | **否**。会员 849 < OTA BAR 899。所谓「比 OTA 贵」是拿深折 799 比 |
| 枝 c 过深 | 相对现行 BAR −5.6%，仍在档 E 带。**若 BAR 再涨而会员 Freeze，则会掉进过深** |
| 枝 a 滞后 | **是**。公开已 +50（849→899，+5.9%），会员 Freeze |
| 「会员必须 10%」 | **拒绝当规则**。10% of 899 = 809，会落到 799 深折带上沿，高峰给会员的折扣开始砸价 |
| 799 | 高峰深折。跟它 / 把会员降到 809 = 把围栏变成深折。P18/P25：高峰关，不报更低一层 |
| Pace | Ahead+Fast，Remaining 56。按 3D 日均 7 间，Days-to-Sellout ≈ 8 < DTA 22 → 压缩倾向（Hypothesis，衰减未给） |

**主诊断：** 公开 BAR 仍低于最低竞对，Ahead+Fast → 允许再小涨；会员应 **同向跟**，保持 −3–5% 围栏。不是倒挂。不是弱日。  
**问题树：** §31 + §7 Pace Ahead + §12（深折层）。  
**不挂：** OCC Low。不因「会员要比 OTA 低」去跟 799。

公开涨幅（幅度卡，不改数字）：

```
现行 BAR 899 vs 最低竞对 929 ≈ −3.2%（<8%，已在带内）
Ahead + Fast → 档 A +5–8% = 944–971
重叠竞对点：949–971；档 D 第一刀不跳 979
执行带：949–969
首选：949（中偏低竞对点，+5.6%）
价已最高? 否
```

## 4. Opportunity / Risk

| ID | 判定 |
| --- | --- |
| 主机会 | 公开收到竞对带；会员跟到新 BAR 的 −3–5%，差价不拉深 |
| 主风险 | Freeze 会员在 849 → 相对 949 约 −10.5%，贴近深折带；或把会员砍到 809「凑 10%」 |
| 假精确 | 不承诺「跟了会员多收 XX 元」 |

## 5. Recommended Action

**主动作：Follow（同向跟，保持围栏），不是 Hold。公开 BAR 949–969 首选 949；会员 902–921 首选 909。高峰关 799。不报新促。禁止 10% 义务。**

本卷对会员三选项的选择：**Follow**（等价 Keep gap 50 元也会落在 899，偏浅；本卷用 −3–5% 带的中位 **909**）。  
不是 Freeze。若用户坚持一次不要拉满会员，可 **Partial**：公开仍 949，会员先到 919（约 −3%），24h 后再收到 909。首选仍写 Follow 点 909。

  Current:            899

  Preferred:          909       # 约 −4.2%；整十

  vs Keep gap 50：    899（围栏只 −5.3%，可接受但偏浅；本卷不选为首选）

                      会员可 Hold 在现行围栏；OTA 围栏 −3–5% 可留；不一夜 −15%

  - 「会员必须便宜 10%」→ 809
  - Freeze 849

## 6. Why

**数据：** DTA22 OTB72% vs STLY62%；3D+21；BAR 899 vs 竞对 929+；会员 849；OTA 深折 799。  
**逻辑：** Ahead+Fast 且价在带内 → 档 A 小涨。无品牌规则 → 自有围栏同向跟，差价保持 −3–5%。849 vs 899 不是倒挂；799 是深折，高峰关。10% 会把会员拖进深折带。  
**Hypothesis：** 3D 速度不衰减则有早售罄倾向；登录墙真实（用户口述）。

---

## 7. Expected Impact

- OCC：接受余下 56 间不全靠 799 / 过深会员填。  
- 公开 ADR：新成交靠近 949。  
- 会员：仍有可见差价（约 40 元），不是 0，也不是 10%。  
- Mix：Member 计划可留；深折层应下降。  
- 办卡转化对 4% vs 10% 的弹性：**Unknown**。不编「不打 10% 就没人办卡」。

| 799 其实平台出资 | 出资页 | 高峰仍不把会员对齐 799；肩日可按 P18 再评 |

## 9. What To Watch / Trigger

```text
1) 未来 24h 净 Pickup ≥ 7 间且 799 已关、会员已到 909
   → 维持 949 / 909。不重开深折。

2) 24h Pickup <3 且直销仍可订平价
   → 不降 BAR。会员可 Partial 到 919（围栏 −3%）。仍不跟 799。

3) 会员价再次 > OTA BAR 层
   → 停涨会员；只同步。

4) 竞对集体到 799
   → 不自动跟。挂 P16。本店深折仍关、会员仍不跟 799。

5) 用户补出品牌义务（例如特许手册写死 5%）
   → 按规则重算；本仿真独立店设定作废该枝。
```
