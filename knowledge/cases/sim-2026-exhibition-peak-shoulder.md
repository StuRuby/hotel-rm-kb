## 4. Recommended Action（必须落到动作）

### A · 9/16 Peak：关低价 + 第一刀 + MinLOS（今天）

```text
Stay Date:            2026-09-16
Current BAR:          899
Range:                999–1049
Preferred:            1029     # Hypothesis；+14.5%，靠中位竞对 1049 的下沿，对齐「不跳最高」
Staging:              第一刀立即；禁止第一刀 ≥1099
Inventory:            关闭预付 799、限时 649 及任何公开可订 <999；BAR Open
                      低价渠道配额收到剩余 30–50%（Hypothesis）
Restriction:          MinLOS=2（覆盖周三夜；到达日按系统挂 9/15 或 9/16，NV-RST-01）
Channel:              9/16 **不报** 店出 15% 大促；该计划在 9/16 关闭
Do-not-do:            一次到 1099；关 BAR；整段会展同一 MinLOS
```

### B · 肩日开着（今天）

```text
9/15 周二（布展肩）:
  BAR 699 → 区间 729–759，首选 729（收到最低竞对，半档，不深涨）
  Open；不设 MinLOS / CTA；主渠道开
  连住包装可选：9/15+9/16 两晚套 ≥ 729+1029 的 0.97 ≈ 1705（均价 853）
  禁止套均价打穿 999
9/17 周四（撤展肩）:
  BAR 679 → 区间 719–749，首选 719（收到最低竞对）
  Open；不 MinLOS
  禁止把 1029 挂到 9/17
  9/16+9/17 套同样不得打穿 999
```

### C · OTA 大促：**不报高峰；肩日也不报 15%**

```text
Who pays:             店出（用户）
店出约 15%：          9/16 → 约 764，打穿新地板 999 → 硬条件不报
                      9/15 → 约 594，低于 729 且深于围栏 −3–5%（699×0.95≈664）
                      9/17 → 约 577，同理
佣金:                 Unknown → 不算假净额
Decision:             三天都 **不报**
                      不是「只报肩日」：因为店出 15% 超过档 E，且不能用平台出资翻案
Close:                该促销 Rate Plan 在 9/15–17 全部关；已有 649 今天关
IF 用户能改成：仅 9/15、9/17，店出 ≤5%，平台不出加佣
THEN 改为「只报肩日」，配额 ≤ 各日剩余 20%
```

硬条件命中：S2（Peak）+ S3（打穿）+ 肩日折扣过深。曝光话术不当门。

### D · 团 40×500 周三：**Counter**（不是拒完事，也不是接）

```text
Displacing:           9/16 为主。ET 用「将满」Hypothesis：
                      剩 64，3D 速度 14/日，DTA 27 → 不接团也会卖。
                      Displaced ≈ 40 间 × Transient 价口径 899–1029（毛）
                      另可能挡 9/15 到达的 MinLOS=2 散客（LOS 肩日 >0，给不出点）
RoomOppCost 量级:     数万（40×约 1000），团客房 40×500=2 万 → 高峰夜单独明显负
Wash:                 入住前 7 天全免 → 高 Wash；无史不编 %
F&B:                  无 → IF
Decision:             Counter
  价:   周三 ≥ 720–800，首选 760（Hypothesis：不低于公开带 70–85% 讨论锚与保本之间；品牌红线优先）
  房量: 周三最多 12 间（剩 64 的约 20%，留尾 20–30% 给高价；Hypothesis）
  或:   改为 9/15+9/16 连住，周三价 ≥720，周二可 680–720
  取消: DTA=14 截止或不可退，否则再砍房
  若团坚持 40@500 单晚无餐 → Reject，留房给出售
Do-not-do:            只说 500<800 所以拒；整段平均接；把尾部整给团
```

**为什么这晚不该再接 500（理论名）：** 9/16 bid price / 机会成本靠近将被挤的散客净价（BAR 将到 1029 一带），500 低于该夜门槛。见 `optimization-advise.md`。不报 EMSR 间夜。

## 5. Why

```
9/16: Ahead+Fast+价低+低价开着+1.2 km 开展
→ 事件旁证成立，第一刀仍用普通尺，不把幅度建在「会展」故事上
→ 先关 649/799，再 899→1029（先库存后涨）
→ 肩日更空 + overnight 合理 → MinLOS=2 只盖 Peak，肩日 Open
店出 15% 盖高峰 = 新开更低库存层，与 P03 相反 → 不报
40@500 挤将满夜 → Counter，不是 500 vs 899
```

## 6. Expected Impact

- 增量成交 ADR 靠近 1029；已售 156 间锁价不进涨价收益。  
- OCC：接受 9/16 减速；64/27≈2.4 间/日即可消化（速度已 14，涨后会降）。  
- 肩日：MinLOS 可能推部分到 9/15；**不保证**填满。  
- 大促：不报可能少弱日曝光；用自有浅包装代替。  
- **禁止报精确增收。**
