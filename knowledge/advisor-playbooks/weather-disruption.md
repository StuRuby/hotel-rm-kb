## 0. 一句话

台风/暴雨/航班大面积取消：**先问需求是被消灭、平移 1–2 天，还是恐慌取消还会回来**；OTB 再高也当 Soft，**禁止涨进取消潮**。  
交通停了 ≠ 价高所以订得满。取消史刚坏 → **停超**。不要用一夜 −15% 填坑。事后 Pace 对照 **无事件基线**，不对照风暴前幻想 OTB。

完成定义：诊断四态 + 十步过程 + 「不涨 / 不砸 / 停超 / 松限制」闸。天气 %、人次、超售间夜 **不编**。

成功标准：用户说「OTB 还很高要不要涨 / 取消潮里能不能降 / 要不要超售」→ 能答下面三句，且不编数字。

```
1. 天气取消潮里 OTB 高 ≠ 该涨；当 Soft。
2. 交通停了是需求消灭/平移，不是价高唯一解释；先别按高峰涨。
3. 取消史刚坏掉就停超；不要用砸价填坑。
```

## 1. 信号（何时进本剧）

进入：用户给出 **天气旗标**（官方预警 / 机场或高铁大面积停运 / 「台风要来了订了又取消」），并且在问涨、降或超售。  
**进入 ≠ 已证实该涨或该降。**

| # | 必须问 | 没有时 |
| --- | --- | --- |
| W1 | 天气事件：官方预警还是口述？影响哪几条 Stay Date？ | Reliability 最多中；禁止把传闻写成 Compression Fact |
| W2 | 取消 vs 新订（24h / 7D），拆预付/灵活 | 只有「OTB 还高」→ 当 Soft，**停涨**，不报取消% |
| W3 | 机场 / 高铁 / 高速是否停或大面积取消 | 未知 → 先当「可能进不来」，不按高峰涨 |
| W4 | DTA、Remaining、当前 BAR、是否已是周末/事件价 | 缺 DTA 不给价 |
| W5 | 超售位：已超数 / Sell Limit 是否还开 | 未知 → 建议先停加超 |
| W6 | 当前 Restriction（MinLOS/CTA） | 未知 → 问；天气夜默认评估是否该 Open |
| W7 | 本店类型：度假进不来 / 机场滞留 / 内陆接收 / 城区商务 | 未知 → 不假设撤离需求 |

**不是本剧本：**

- 无天气旗标的日常高取消 → P14。  
- 今晚物理赶客、已经超了 → P24 今晚程序；本剧只答「还加不加油」。  
- DTA≤3、交通已恢复、真剩余、价显著高于可订竞对、市场不冰 → 才可能滑到 P05 短窗，不是本剧默认降。  
- 演唱会/展会取消 → P07/P17 回平日带，机制同类。

## 2. 先诊断：四态（先诊断枝）

天气对住宿不是单方向。STR/CoStar 打开页：飓风 **路径内** 市场 RevPAR 掉，**撤离/抢修接收城** 升（美国 2024 Helene/Milton 周报，**A/B，百分比不进本库启发式**）。台湾厂商文（**C**）称退订与滞留可同时发生。本库用四态，不编「台风夜 OCC 必到 X%」。

| 态 | 识别 | 需求含义 | 默认价/库存 |
| --- | --- | --- | --- |
| **A 消灭** | 机场/高铁/高速官方停运，或景区/本店不可达 | 今晚需求没了，不是「价贵」 | **不涨**。市场冰 → `do-not-cut`。OTB 当 Soft。停超。MinLOS **Open** |
| **B 平移** | 交通 1–2 天后恢复；取消里大量改期意向 | 洞在今晚，量在相邻日 | **不涨今晚**。不把今晚洞用 −15% 填。相邻日按 Pace 再评，禁止自动当 Peak |
| **C 恐慌取消** | 预警刚出、交通未停、取消≥新订、再订落到更低价或别店 | OTB 含金量掉，部分还会回来 | **Soft OTB，停涨**。不加大超售。不加深折扣「锁单」（P14） |
| **D 滞留/撤离** | 机场店/交通节点、或内陆接收城；walk-in / 延住升 | 可能有短 Lead 增量 | **仍禁止趁灾哄抬已确认订单**。价稳、透明、可订。不把美国抢修周 ADR 涨幅抄来。价已最高只关不涨 |

先排除（没过不许涨、也通常不许砸 BAR）：

| # | 排除 | 成立时 |
| --- | --- | --- |
| E1 | OTB% 当硬需求 | → Soft；本卡 `dont-raise-into-cancel-wave` |
| E2 | 一团洗 / 一场演出取消被叫成台风 | → P14 E3 / P07，不当天气病 |
| E3 | 改期被算成取消+新订 | 看净占用 |
| E4 | MinLOS/CTA 把改期短住挡在门外 | → P33：**先松限制，不要先降 BAR** |
| E5 | 渠道关 / 不可订造成「看起来空」 | 只修供给 |
| E6 | Forecast 仍按风暴前高峰 | → P17 事件错：先改 overlay |
| E7 | 用风暴前 OTB 当 Pace 锚 | → 对照无事件 STLY（P32 表亲） |
| E8 | 无取消史却要「超 N 间」 | **不给间夜** |

「正常」取消率：**本店同 DOW × 同政策 × 同 DTA 窗**。无史 → Unknown，**不报行业取消%**（P14）。台风人次 / 航司取消率官方映射 → **NV**，不映射到单店 OCC。

## 3. 诊断落格 → 动作类型

| 结论 | 条件 | 动作类型 | 首选 |
| --- | --- | --- | --- |
| **停涨 + Soft** | 取消潮 + OTB 看起来 Ahead | `什么都不动` 于 BAR；OTB 不当硬需求 | 不涨；盯 24h 净 Pickup |
| **回平日/无事件带** | 已按台风/周末高峰挂上，但交通消灭或 Pace 只领先于风暴前幻想 | `预测修正` + 可能撤 overlay | 对照无事件基线；**不是**从幻想价砍到仍贵（P32） |
| **Hold 公开 BAR** | 态 A/C 且价已在可订带；或市场冰 | `什么都不动` | `do-not-cut` |
| **先松限制** | MinLOS/CTA 开着 | `限制` | Open 该天气夜；肩日不要误伤 |
| **停超** | 取消史刚坏、或已超且到达不确定 | `库存`（Sell Limit 方向） | 停加超；无史不给间数 |
| **围栏** | 仅当：交通已恢复或未停 + 真剩余 + 价高 8–15% + 市场不冰 + 限制已开 | `定价` 围栏 | **−3–5%**；BAR 不动 |
| **降 BAR** | 上款仍成立且价高≥15% + 7D/3D 真慢 | `定价` | BAR **−5–10%**；禁止一夜 **−15%** |
| **P05 短窗** | DTA≤3、交通恢复、真剩余、竞对可订且自己显著贵 | 有截止日期的战术 | 仍禁止无期限 −15% |
| **承接滞留** | 态 D 且库存真开 | `库存` + 价稳 | 透明可订；不现场加价已确认单 |

禁止第五项：「OTB 80% 适当涨一点」。  
禁止：「取消了一块，今晚 −15% 填回去」。  
已经降过一刀且 OCC↑ RevPAR↓ → `stop-cut-if-revpar-falls`，停第二刀。

## 4. 十步过程（顾问内部，可对用户压缩）

```text
1. 旗标：官方气象 / 机场 / 铁路，还是口述？覆盖哪些 Stay Date？
2. 四态：消灭 / 平移 / 恐慌取消 / 滞留。可以两态同时（进不来 + 走不了）。
3. Soft：24h/7D 取消 vs 新订。OTB 当 Soft（P14）。禁止按硬需求涨。
4. Forecast：撤掉风暴前高峰 overlay（P17）。对照无事件 STLY，不对照昨天幻想 OTB。
5. 价：默认停涨。市场冰或不达 → 不砸公开 BAR。只在真弱+价高+供给开+市场不冰 才围栏 −3–5% 或 BAR −5–10%。
6. 库存：主 BAR 可订；把确定不来的占位尽早看成可售（虚假 OTB），但不要把还没取消的当空房去超卖。
7. 超售：取消史刚坏 → 停加超（P24）。无史不给精确间夜。预付主导 → 默认不超。
8. 限制：天气夜 MinLOS/CTA 评估 Open（P33）。Peak MinLOS=2 只盖已证实、交通仍通的 Peak。
9. 渠道：不报砸高峰的当晚大促（P18）。改期优先于加深折扣锁单。佣金% 用户给，不编。
10. 事后：交通恢复后，Pace vs 无事件基线。洞填不上也不从幻想价广告式回落。写 24/48h Trigger。
```

动作表（对用户输出）：

```text
Stay Date:
Weather flag:     官方 / 口述；消灭 / 平移 / 恐慌 / 滞留
Cancel 24h / 7D vs 新订:
OTB:              Soft（不按硬需求涨）
DTA / Remaining / BAR:
Overbook:         停加超 / 已超则走 P24 今晚程序
Restriction:      天气夜 Open / 保留已证实 Peak MinLOS
Decision:
  涨？            否（取消潮中默认）
  降？            否，除非真剩余+价高+市场不冰+限制已开
                  围栏 −3–5% / BAR −5–10% / 禁止一夜 −15%
  超？            停；无史不给间数
Do-not-do:
  - OTB 高所以涨
  - 取消潮里加大超售
  - 一夜 −15% 填坑
  - 报行业取消率 / 台风人次 / 超售 N 间
  - 对照风暴前幻想 OTB 判落后
  - 对已确认订单事后加价
```

## 5. Trigger

| 事件 | 动作 |
| --- | --- |
| 24h 取消回落到本店同窗史，且交通恢复 | OTB 可重新当硬信号；再评 P01/P09 |
| 官方停运 / 不可达 | 当晚按态 A：停涨、停超、Open 限制；不砸 BAR 抢不存在的量 |
| 交通 24–48h 内恢复、改期意向高 | 态 B：今晚 Hold；相邻日按各自 Pace，不自动涨 |
| 价已最高还想涨 | **只关不涨** |
| 已经降了一刀 OCC↑ RevPAR↓ | 停再砍（stop-cut） |
| Remaining 真空 + DTA≤3 + 交通已通 + 价显著高于全部可订竞对 + 市场不冰 | 才允许滑到 P05/P02 围栏或浅砍 |
| 机场 walk-in 明显升（用户给） | 态 D：保持可订与透明价；仍不涨进取消潮、不加超 |
| 预警解除但 BAR 仍挂风暴高峰 | 撤 overlay 到无事件带；禁止 幻想价→中间价 广告式回落 |

## 6. 如果只能再补 3 个

1. 交通是否真停（机场/高铁/高速官方或用户能给的精度）+ 影响哪几晚。  
2. 24h 取消 vs 新订（最好拆预付/灵活）。没有就 **OTB=Soft、停涨、停超**。  
3. 无事件基线：同 DOW STLY BAR/OTB，或当前无事件可订竞对。

缺 1：不按高峰涨，也不按滞留涨。  
缺 2：不给超售间夜，不给「正常取消率」。  
缺 3：禁止从风暴价公开大砍；只允许停涨 + 天气夜 Open 限制。
