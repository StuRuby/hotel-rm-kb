# Metric｜Livestream / Host-Exclusive vs Public BAR（轻）

> 路径：`metrics/livestream-vs-public-bar.md`  
> 配：P77  
> 状态：drafted 2026-08-29 22:17  
> **无默认直播折扣 %、无「主播必须打 X 折」、无「卖爆了 = 市场价」、无佣金%、无直播时长 Fact**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 直播间 / 主播专属 / 橱窗挂牌（用户给；不编）
- gap = 公开 BAR − 直播挂牌（只观察，不推导必须折扣）
- 是否日历房 RatePlan / 预售券 / 通兑券 / 达人专场（能拆就拆；拆不清标 NV）
- 商品是否带窗 / 库存帽 / 核销限制
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成主播价 / 卖爆了所以跟」

## 不用来做什么

- 不推导「直播该便宜多少 / 主播该抽几成」
- 不把直播成交价写成公开 BAR
- 不因「直播间卖爆了 / 主播价就是市场价」自动砍公开尺
- 不把 TechNode 40%/60–90%、中国旅游报「两三成」抽成写成中国 Fact
- 不发明直播折扣 % / 主播佣金% / 直播时长

## 调用

早会/调价前看：公开 BAR；直播商品是否被当成尺；有没有人要求 BAR→主播价。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁直播借口一夜 −15%；围栏须有截止日）。

本店直播 SOP / 华住字段 / 达人佣金计划 = **NV**。
