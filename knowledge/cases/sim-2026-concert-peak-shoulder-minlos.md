## 2. Situation

300 间仿真店。分析日 9/19。10/03 周六演唱会，场馆 2.5 km、晚场，用户认为 overnight。10/03 DTA 14，OTB 68%=204 间，剩 96，3D +36 / 7D +81，vs 无事件 LY +13pp，BAR 899 vs 竞对 999–1099，预付 799 与限时 699 仍开，无 MinLOS。肩日 10/02 OTB 38% 仅领先无事件年 2pp，BAR 799 vs 849–929；10/04 OTB 29% 略落后，BAR 759 vs 799–859。用户问 3 号限不限单晚、低价关不关、肩日怎么卖。国庆整段其余日未给。

| D10 | Forecast 未给。 |

```
Fact: 10/03 Ahead+Fast+价低+低价开着；肩日 OTB 明显低于 Peak（38%/29% vs 68%）。
High-probability: 10/03 是事件 Peak + Underpricing + 单晚切高峰风险。
Hypothesis: overnight 成立；1029 幅度；MinLOS=2 能把部分需求推到 10/02。

```

**主诊断：** 10/03 是已证实旁证的 Concert Peak，主风险是按 899/699 卖穿并把肩日留空。  
**次诊断：** 肩日不是垃圾日，也不是第二高峰。  
**问题树：** §16 + §7 + §5 + §8 路径。  
**剧本：** P07；库存先后走 P03 逻辑；限制走 minlos-peak-protect。

## 4. Recommended Action（1 主 + 2 配套）

### A · 10/03 价 + 关低价（今天）

```text
Stay Date:            2026-10-03
Current BAR:          899
Range:                999–1049
Preferred:            1029     # Hypothesis；+14.5%，对齐中位竞对
Staging:              第一刀立即；禁止第一刀 ≥1099
Inventory:            关闭预付 799、限时 699 及任何公开可订 <999；BAR Open
                      低价渠道配额收到剩余 30–50%（Hypothesis）
Restriction:          见动作 C
Channel:              10/03 拒打穿 999 的 OTA 大促
Do-not-do:            一次到 1099；只改一个渠道；关 BAR
```

### B · 肩日（今天）

```text
10/02:
  BAR 799 → 区间 849–899，首选 869（Hypothesis，半档/靠最低竞对）
  不关主渠道；不设 MinLOS / CTA
  可做「2–3 日连住套」：三晚打包不低于 869+1029+799 的 0.97（围栏 −3%，Hypothesis）

  BAR 759 → 区间 799–829，首选 799（收到最低竞对，不深涨）
  Open，不 MinLOS
  禁止把 10/03 的 1029 挂到 10/04
```

### C · 限单晚（今天做，因为肩日已齐）


## 5. Why

```
10/03: Pace Ahead + Fast（中位 DTS 仍 < DTA）+ 价低 + 低价开着 + 晚场 2.5 km
→ 事件旁证成立，但仍用普通第一刀尺，不把幅度建在演唱会故事上
→ 先关 699/799，再 899→1029（先库存后涨，与 P03 一致）
→ 肩日明显更空 + overnight 合理 → MinLOS=2 只盖 Peak，肩日开着
```

Competitor Rate 是锚不是目标：不一次上 1099。

## 6. Expected Impact

- 增量成交 ADR 靠近 1029；已售 204 间锁价，不进涨价收益。  
- OCC：接受 10/03 减速；只要剩余 14 日均 ≥7 间仍可消化（96/14≈6.9）。  
- 肩日：MinLOS 可能把部分周六单晚变成周五到达；**不保证** 10/02 填满。  
- 禁止报精确增收。

## 7. Risk → Trigger

| 风险 | Trigger |
| --- | --- |
| 1029 过激 | 10/03 24h Pickup <3 → 守 1029 再 24h；48h 累计 <5 → 999，并解开 MinLOS |
| 一团假快 | 单笔 ≥40 → BAR 上限 999，撤 MinLOS |
| overnight 假 | 场馆证实当日往返为主 → 取消 1049+，撤 MinLOS，按普通 Ahead 上限 999 |
| 独限被掏空 | 竞对全开单晚且 24h <3 → 解开 MinLOS，价守 999–1029 |
| 肩日被关错 | 10/02 不可订 → 先开 BAR 层 |
| 国庆中段空城 | 未给数据；不把 1029 延到 10/05–07 |

加码：10/03 24h ≥8 且非一团、最低竞对仍 ≥999 → 第二刀 1049–1099 首选 1069。肩日不加第二刀除非肩日自己 Fast。
