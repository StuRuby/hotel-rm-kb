# Metric｜Coupon-After vs Public BAR（轻）

> 路径：`metrics/coupon-after-vs-public-bar.md`  
> 配：P74  
> 状态：drafted 2026-08-29 10:17  
> **无默认券折扣 %、无「平台补完必须跟」、无「券后价 = 市场价」、无佣金%/出资%**

## 定义（Hypothesis 计数尺）

- 本店公开灵活 BAR（用户给）
- 券后 / 平台补贴展示挂牌（用户给；不编）
- gap = 公开 BAR − 券后挂牌（只观察，不推导必须折扣）
- 谁出资（酒店同意 / 平台自掏 / Unknown）
- 券是否带资格码、报名窗、登录条件
- 本店 Remaining；Pace（Ahead / On / Behind）
- 拟议是否「BAR 改成券后价 / 跟平台补贴」

## 不用来做什么

- 不推导「券该便宜多少」
- 不把券后挂牌写成公开 BAR
- 不因「券卖得好 / 平台补完」自动砍公开尺
- 不把 DirectYourBookings 截图 $ / HotelTechUpdate 阈值写成中国 Fact
- 不发明出资% / 佣金% / 券门槛

## 调用

早会/调价前看：公开 BAR；券后是否被当成尺；有没有人要求 BAR→券后。  
Ahead 且剩余紧 → Hold。  
Behind 才把剩余交给 P05（仍禁券后借口一夜 −15%；围栏须有截止日）。

本店券 SOP / 美团·携程出资字段 = **NV**。
