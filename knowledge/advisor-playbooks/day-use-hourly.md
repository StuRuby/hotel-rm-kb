## 0. 一句话

钟点房先问这间晚上还能不能卖过夜，能交回才是增量。  
晚上还卖过夜 BAR，不要用钟点把那晚占掉。  
钟点价不是过夜 BAR，别把钟点价写成新门市价。

完成定义：一张「钟点/day-use → 交回晚房则评增量 / 挡夜则当便宜过夜 / 高峰关或限额」过程。P05 管 **过夜** 渠道 last-minute；P42 管 **过夜** 前台口价；本剧接管 **白天小时产品会不会吃掉当晚过夜库存**。

顾问必须能直接说的三句：

```
1. 钟点房先问这间晚上还能不能卖过夜，能交回才是增量。
2. 晚上还卖 799，不要用 199 钟点把那晚占掉。
3. 钟点价不是过夜 BAR，别把 199 写成新门市价。
```

（199 / 799 是本库 Hypothesis 带 + Simulation 点，不是钟点行情 Fact。199 只允许出现在 Simulation 与上列三句。）

| 形 | 看起来 | 实际 | 默认动作 |
| --- | --- | --- | --- |
| **A 高峰晚 / Pace Ahead / 过夜剩余偏紧** | 「下午钟点很火，今晚还接不接散客？」 | 钟点在抢同一物理房的晚到窗口 | **关或紧限额** 钟点。过夜 BAR **Hold**（Hypothesis 779–799 首选 799）。不把钟点价当过夜口价 |
| **B 挡夜的钟点** | 延迟退房 / 过夜钟点 / 房态关到次日 | 这是便宜过夜，不是增量小时 | **当 dump 过夜 BAR。** 走 T19/T20/P05 逻辑：机会成本 ≈ 过夜贡献。不要开 |
| **C 要把钟点价写成过夜 BAR** | 「钟点 199 卖得动，今晚也挂 199」 | 一夜把公开过夜基准砸穿 | **拒绝。** 禁一夜 −15% 当永久 BAR |
| **D 弱平日过夜 / 晚市冰 + 能交回** | 「周二白天钟点还能卖，晚上空」 | 晚到需求弱或能周转交回 | **可开**，若净 > 贡献（**含加一次 HK 周转**）且房能在晚到前交回 **或** 当晚过夜已冰。仍不是新过夜 BAR |
| **E 其实是 OOO / 过夜 walk-in / OTA 今夜过夜特价** | 「空着的维修房开钟点」「前台今晚跟 399」「OTA 今夜特价」 | 走错剧本 | OOO 未释放 → **P37**，不是钟点库存。过夜上门 → **P42**。OTA 今夜过夜 dump → **P05** |

独立默认（本库 Hypothesis）：

- Day-use / 钟点默认占 **白天小时**（常见公开槽约上午到傍晚；厂商例 11:00–17:00）。**不是**过夜产品。  
- **能交回晚到 + HK 能周转** → 弱过夜夜才评增量。  
- **交不回 / 延迟离店挡 15:00–20:00 入住 / 房态关到次日** → 按便宜过夜处理，不是增量。  
- 高峰晚 Pace Ahead：默认 **关或紧限额**（配额、最早离店死线、指定房号/楼层）。  
- 钟点价 **不得** 覆盖公开过夜 BAR。  
- 加一次客房周转是 T19 的增量变动成本；无成本数不说「总比空着强」。  
- STR：真 day-use 按不过夜卖；6pm 前离且不是已发布/协议段房价 → 记 Day Use，不记该段 rooms sold。编进段的日用房同日再卖，OCC 可以 >100%。

7) 晚到高峰时刻（用户说几点开始入住）

## 3. 分叉闸（开钟点 / 改过夜 BAR 前必过）

```
0  问的是白天小时产品，还是过夜口价/OTA 今夜过夜特价？
     过夜上门 → P42。OTA 今夜过夜 dump → P05。本剧停主座。
1  Remaining 是可售过夜吗？（P37）
     维修/锁未释放 → 不是钟点燃料。
2  这间钟点晚上还能不能卖过夜？
     交不回 / 离店过晚 / 房态关到次日 / HK 明确做不完
           → 形 B。当便宜过夜。高峰默认不开。
     能交回（离店死线在晚到前 + HK 能周转）
           → 看 3。
3  该夜过夜需求是否 Ahead / 剩余偏紧 / 未冰？
     是 → 形 A。关或紧限额。过夜 BAR Hold。
     晚市冰或弱平日且能交回 → 形 D。可开，净须过 T19（含加一次 HK）。
     未知 → 当未冰（形 A）。缺数不默认全开钟点。
4  有人要把过夜 BAR 改成钟点价 / 一夜 −15%+？
     → 形 C。拒绝。
5  拟议钟点净 ≤ 加一次周转成本，或挡夜时净 ≪ 过夜贡献？
     → 拒绝该产品。无成本则弱结论：高峰不要用远低于过夜 BAR 的小时价去占夜。
```

**禁止跳到「下午卖得很火所以晚上也要让路」。** 火的是小时需求，不是把过夜 BAR 降到钟点价的许可证。

STR（S）：day-use 的定义前提是 **不过夜**。一旦实际过夜或按过夜段编码，就不是增量小时，是 rooms sold。  
Prostay（Vendor B）：sell-out 日与早到高峰日应关 day-use；失败模式是晚到客人走进未周转房。  
Mews（Vendor B）：白天小时与过夜不是自动二选一；能周转才能卖两次。  
Dayuse（Vendor B）：典型公开槽约 11:00–17:00；配额随运力加减——这是围栏形态，不是必须接专平台。

## 5. 十步过程（顾问内部，可对用户压缩）

```text
1. 钉 Stay Date = 可能被占的过夜夜。不是「今天下午」这个钟点。
2. Remaining := 可售过夜（P37）。假空不开钟点。
3. 拆产品：时段、离店死线、是否过夜钟点、拟议价、渠道。
4. 问晚上还能不能卖过夜：死线 vs 晚到曲线；HK 能否加一次周转。
5. 分叉 A 关/限额 / B 当 dump 过夜 / C 拒改 BAR / D 弱日可开 / E 移交。
6. 贡献：能交回 → 钟点净 − 加一次 HK。挡夜 → 还要减被挤的过夜贡献（未知过夜贡献则不要用远低于过夜 BAR 的小时价去占夜）。
7. 无三成本：不说总比空着强。高峰缺成本仍关/限额（弱结论）。
8. 形 A 限额若开：小配额、离店死线在晚到前、指定房/楼层、当晚失效；公开过夜 BAR 不动。
9. 过夜 BAR：Hold。禁止把钟点价写成过夜 BAR。禁一夜 −15%。
10. 输出：钟点 Open/Close/Cap + 过夜 BAR 动不动 + 交回死线 + Trigger。
    不输出中国钟点价表。无 Pace 声明 Hypothesis / 偏 A。
```

### 5.1 动作表

```text
Stay Date:            被占的过夜夜
Day-use window:       用户时段；未知则假设需在晚到前离店
Can return?:          能交回 | 不能 | 未知（未知高峰当不能）
Overnight demand:     Ahead/紧/未冰 | 冰 | 未知（未知当未冰）
Public overnight BAR: Hold；不改成钟点价
Day-use product:      形 A → Close 或紧 Cap
                      形 B → 当过夜 dump，不开
                      形 D → Open 若净过 T19 且能交回或晚市冰
Fence:                钟点 ≠ 过夜 BAR ≠ P05 今夜过夜特价 ≠ P42 前台过夜口价
Expiry:               限额当日失效；次日过夜 BAR 恢复（本就不应被改）
Do-not-do:
  - 高峰全开钟点占晚到
  - 199 写成新过夜 BAR
  - 一夜 −15% 当永久过夜 BAR
  - 无成本说钟点总比空着强
  - 编佣金% / 钟点价表 / 保洁分钟 / 华住 SOP
  - 顾问代改房态 / 代排 HK
Trigger: 见 §6
```

无 RMS 时的最小手算（Hypothesis，不是厂商算法）：

```
DayUse_gross      = 用户拟议钟点价（无则不发明）
DayUse_net        = DayUse_gross − 渠道成本（若知；不知则声明高估了净）
Extra_HK          = 用户给出的加一次周转变动成本（不知 = Unknown）
Overnight_contrib = 过夜 BAR 净 − 过夜变动成本（不知则不报精确差）

能交回:
  Incremental ≈ DayUse_net − Extra_HK
  规则：Incremental > 0 才评开（形 D）；形 A 即使 >0 也默认关/限额

挡夜:
  Incremental ≈ DayUse_net − Extra_HK − Overnight_contrib
  规则：高峰默认 <0。不要用远低于过夜 BAR 的小时价占夜
```

Prostay 文中的「50–70% 过夜价 / 15–25 加清洁」= **Vendor 算术例，不进本库幅度、不进中国成本**。

## 6. Trigger

| 事件 | 动作 |
| --- | --- |
| 过夜 Pickup 仍正 / 竞对公开满 | 守形 A。关或收回钟点配额 |
| 形 D 开出后晚到突然变热 | **立刻关** 钟点新单；已在住钟点死线不放宽 |
| HK 说交不回 / 已出现晚到进脏房 | 停钟点。形 A 升级为硬关 |
| 销售要把过夜 BAR→钟点价 | **拒绝。** T19/T20；禁一夜 −15% |
| 取消潮导致过夜变空 | 才评形 D；仍要交回死线或确认晚市冰 |
| 用户补加清洁成本 | 重算形 D 贡献；不改形 A 默认关/限额 |
| 发现拟议「钟点」实际住到次日 | 改判形 B，按过夜 dump 关 |

## 7. 如果只能再补 3 个

1. **当晚可售 Remaining + Pace/Pickup + 过夜 BAR** — 翻转形 A vs 形 D；缺则当未冰，不默认全开钟点  
2. **离店死线能否在晚到前 + HK 能否周转** — 翻转增量 vs 便宜过夜；缺则高峰当交不回  
3. **加一次清洁成本或过夜贡献（有一个就算闸）** — 翻转「总比空着强」；缺则高峰仍关/限额，弱日不说必开

缺 1：Confidence Low，钟点偏关，过夜 BAR Hold。  
缺 2：高峰按形 B/A 关。  
缺 3：拒绝「199 总比空着强」；形 A 仍关。

## 8. Confidence / 边界

Pace 齐 + 能判断交不交回：方向 **Medium**；点价永远 Hypothesis。
