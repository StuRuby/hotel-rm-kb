## 3. 卡立了什么（一句话 + 五点）

**一句话：** 份额指数已经发生之后，它只允许改诊断，不允许改今夜 BAR。

1. **100 是公平份额标记，不是目标价。** MPI/ARI/RGI 是相对某一命名组的比。没有真 Comp Set 就没有指数。100 = STR fair share，不是 BAR、不是品牌地板、不是中国官方线。禁止发明「RGI 必须 ≥ X」。
2. **指数大多是事后尺。** 月报 STAR 主体是已经住过、已经卖掉的间夜。砍今夜 remaining 拉不回那些夜，只重定价未售库存，并稀释本来会卖的 — 稀释形状同 P56，病因不同（份额表 ≠ 预算表）。RGI 像 T-Hall 的厅占用、T-Guar 的混合 OTB：画面上的数不是杠杆。
3. **隐藏的分母是集合。** Comp 构成、一家竞对 OOO、活动夜、mix、STR vs PMS 分母都会动指数，而不等于本店「定价错了」。故 P57 形 E/F 存在 — 本卡只点，不重复六形。
4. **读三连，不读单点。** MPI × ARI / 100 ≈ RGI（已在指标卡）。低 RGI + 高 ARI = 量份额故事，不是自动「我们太贵」。高 MPI + 低 ARI = 便宜份额故事。两句都不是 BAR 指令；下一步是该夜 Pace / Pickup / Remaining（P01 vs P05）。
5. **假尺子一族 + 中国非 STR。** T-Share 与 T-Guar / T-Status / T-Comp / T06 / T-Hall / T-Reputation 同族（画面数 ≠ 按钮），对象不同。无 STR → 点名 3–5 家，方法 Hypothesis，不发明中国官方 MPI。五个问句（订阅 / 集合 / 日期窗 / STR vs PMS OCC / 该周六 Pace）**全部 NV，本卡不代答**。
