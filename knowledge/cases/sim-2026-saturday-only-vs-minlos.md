手算（Simulation 算术，不是增收预测）：

```
拒 Sat-only、若转成 Fri–Sat @ 699+799 = 1498   vs  Sat-only 799
拒 Sat-only、若转成 Sat–Sun @ 799+659 = 1458   vs  Sat-only 799
砍 Sat→699 的三晚套 (699+699+659)=2057 vs 现行 (699+799+659)=2157
  → 同一三晚少 100，且高峰夜贡献被拆
```

不把 1498/1458 写成「一定会发生」。肩日需求是 High-probability，不是 Fact 锁定。

## 5. Recommended Action · **拒 Sat-only；MinLOS=2；Hold 周六 779–799 首选 799；拒绝 699**

**不接只要周六的一晚。不把周六 BAR 降到 699。不编连住均价公式。**

```text
Hotel: 180 间 Simulation 独立店（非真店）
Brand: 自有围栏；无声明底 → 不发明 699

2026-08-29 周六（DTA 6，Ahead+Fast，肩日非冰）
  单晚 Sat-only:       REJECT
  Restriction:         MinLOS=2 盖 8/29（双口径：到达日=8/29 必须 ≥2 晚；
                       覆盖夜=住 8/29 的 stay 必须 ≥2 晚——用户按 PMS 落地，NV-RST-01）
                       CTA 周六：本卷主到达日未知 → **先不用 CTA**，避免挡「周六到住两晚」
                       不与 MinLOS 叠
  周五 8/28 / 周日 8/30: Open；不 MinLOS / 不 CTA
  MaxLOS:              不设。不要切 Fri–Sun 的 BAR 连住
  公开 BAR 周六:        779–799，首选 799
                       （Hold。第一刀是限制。+6.7% 未出局；Ahead 不跳最高）
  周五 BAR:            699 Hold
  周日 BAR:            659 Hold
  三晚套:              可选。套内周六仍 799。
                       加权地板 (699+799+659)×0.97 / 3 ≈ 697 → 现行均价 719 已在上
                       **禁止**为了把均价做低去改周六=699
  肩日围栏:            不必须。若要促肩日：只动周五/周日档 E −3–5%，高峰不动
  已订 Sat-only:       不暗改已确认规则（P38 同向：已确认不暗改）
  Do-not-do:           接 Sat-only；BAR→699 / −12.5%；一夜 −15%；
                       编 OTA 均价公式；整周 MinLOS；MinLOS+CTA 叠死

若 24h 周六 Pickup <3 且短住拒单升且竞对全开单晚：
  解开 8/29 新 MinLOS；低价不自动重开；价仍 779–799 首选 799
若 24–48h 仍 Ahead+Fast、价未最高：
  才评 P09 第二刀 +5–8% 或不跳最高（829 是天花板参考，不跳）
  限制仍可守
若肩日 Pickup 转 0、市场转冰：
  改评形 B：开单晚；仍不砍 799→699
```

**首选 799** 的理由：问题是停留形态，不是价出局。高峰该贵。砍 699 是用高峰买肩日。

**区间 779–799：** 若用户坚持「给个带」，下限是心理微调不是 dump。不要写成已经降了。

**MinLOS 而不是 CTA：** 本卷不知道主到达日。Lighthouse：主到达日是周六则 CTA 反噬。故第一刀 MinLOS=2。
